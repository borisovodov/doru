# Scorciatoie da tastiera

Dóru segue le consuete convenzioni degli editor: su macOS le scorciatoie usano
⌘, su Linux e Windows Ctrl; Shift e Alt/Option (⌥) sono uguali ovunque. Le
combinazioni di scorciatoie (con ⌘/Ctrl/Alt) funzionano ovunque, compresi i
campi di testo e l'input della chat; la semplice digitazione non attiva mai una
scorciatoia.

## Progetti

| Azione | macOS | Linux / Windows |
|---|---|---|
| Nuovo progetto… | `⌘N` | `Ctrl+N` |
| Nuova finestra | `⌘⇧N` | `Ctrl+Shift+N` |
| Apri progetto o importa GEDCOM… | `⌘O` | `Ctrl+O` |
| Salva | `⌘S` | `Ctrl+S` |
| Esporta GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Apri impostazioni | `⌘,` | `Ctrl+,` |

## Viste

| Azione | macOS | Linux / Windows |
|---|---|---|
| Apri la barra laterale Cerca | `⌘⇧F` | `Ctrl+Shift+F` |

La scorciatoia apre la barra laterale Cerca e posiziona il cursore nel campo di
ricerca, pronto per digitare.

## Schede

| Azione | macOS | Linux / Windows |
|---|---|---|
| Chiudi scheda | `⌘W` | `Ctrl+W` |
| Scheda successiva | `⌘⇧]` | `Ctrl+Tab` |
| Scheda precedente | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Passa alla scheda 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Il passaggio tra le schede è circolare: dopo l'ultima si torna alla prima.
`⌘9` (`Ctrl+9`) salta sempre all'ultima scheda, anche quando ne sono aperte meno
di nove.

## Modifica

| Azione | macOS | Linux / Windows |
|---|---|---|
| Annulla | `⌘Z` | `Ctrl+Z` |
| Ripeti | `⌘⇧Z` | `Ctrl+Shift+Z` |

Ogni azione sulla tela — inclusa l'aggiunta di una persona insieme al suo
collegamento familiare — è un singolo passaggio annullabile; anche le modifiche
fatte dagli agenti IA possono essere annullate.

## Pannelli

| Azione | macOS | Linux / Windows |
|---|---|---|
| Mostra/nascondi il pannello della chat | `⌘⌥B` | `Ctrl+Alt+B` |

## Durante la digitazione

Alcuni tasti si comportano in modo speciale nei campi di input:

- **Chat**: `Enter` invia il messaggio.
- **Ricerca nell'albero**: `Esc` cancella la casella di ricerca.
- **Editor persona**: `Enter` nella casella delle note aggiunge la nota
  digitata.

## Scorciatoie standard dei menu

I menu File/Modifica/Visualizza/Finestra includono gli acceleratori standard
della piattaforma: copia, taglia, incolla e seleziona tutto; zoom avanti, zoom
indietro e reimposta zoom; schermo intero; ricarica e strumenti di sviluppo;
riduci a icona, chiudi finestra ed esci. Questi seguono le convenzioni del tuo
sistema operativo e non sono elencati qui.

## Promemoria

Con tutte le schede chiuse, l'editor vuoto mostra un esempio a rotazione di
cinque scorciatoie come promemoria; chiudi e riapri una scheda per vederne un
altro set.

## Note

L'apertura di un file `.ged`/`.gdz` tramite **Apri progetto o importa
GEDCOM…** importa l'albero in un nuovo progetto non ancora salvato.
L'esportazione avviene nella scheda **Esporta GEDCOM**, che offre GEDCOM 7.0 e
GEDZIP (vedi [Avvio rapido](getting-started.md)).
