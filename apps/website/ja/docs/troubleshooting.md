# トラブルシューティング

- **古いビルドの `.doru` プロジェクトが開けない** — 1.0 より前は、プロジェクトのスキーマがマイグレーションなしで変更されるため、別のビルドで書き込まれたファイルは理解されません。そのプロジェクトを作成したビルドで開き、GEDCOM をエクスポートして、そのファイルをこのビルドにインポートしてください。
- **「AI プロバイダーが設定されていません」** — 設定（左バーの歯車アイコン）を開き、プロバイダーを選び、ウィザードに従います：モデル一覧を取得する（またはモデルを選ぶ）か、必要な場所でキーを保存します。
- **Ollama への接続に失敗する** — Ollama プリセット（ベース URL `http://localhost:11434/v1`）を選択してください。API キーは不要です。「プロバイダーからモデルを取得」を押します——プロバイダーに到達できないと表示された場合は、Ollama がローカルで実行されていることを確認してください。
