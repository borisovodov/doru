# データとバックアップ

- あなたのデータはプレーンなファイルであり、あなたのものです。Dóru にはアカウントもクラウドバックエンドもテレメトリもありません。*あなた*がリモートの AI プロバイダーを設定しない限り、何もどこにもアップロードされません——その場合でも、チャットのメッセージと、アシスタントがツールを通じて取得した家系図データがそのプロバイダーに送信されます。すべてをコンピューター上に保ちたい場合は、ローカルプロバイダー（Ollama、LM Studio）が完全にオフラインで動作します。
- バックアップするには：プロジェクトに書き込む可能性のあるすべてのプロセスを停止します——Dóru でプロジェクトを閉じ、MCP クライアントやその他のツールも停止します——その後、`.doru` ファイル（写真がある場合は隣の `media/` フォルダーも）をコピーします。それだけです。復元はそれをコピーして戻すだけです。
- チャットセッションはアプリのデータディレクトリに保存され、`.doru` ファイル内にはありません。必要なら別途バックアップしてください。
- ファイルはバージョン管理に適しています。安定したバイナリファイルなので、必要なら git にコミットできます。

## マシン間の同期

Dóru には組み込みの同期エンジンはありません——プロジェクトはプレーンなファイルであり、同期を保つのはあなたの仕事です：iCloud Drive、Dropbox、rclone、rsync、USB メモリなど、お好みの方法で。

1 つ注意点があります。`.doru` ファイルは SQLite データベースであり、**開いている**プロジェクトをファイル同期ツールでライブ同期すると、書き込み途中の状態でファイルがコピーされ、破損する可能性があります。安全な方法は、同期する前にプロジェクト（またはアプリ）を閉じ、他に書き込んでいるプロセスも停止することです。閉じていて他の書き込みがないプロジェクトのコピーは常に安全です。
