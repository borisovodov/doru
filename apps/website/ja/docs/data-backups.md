# データとバックアップ

- あなたのデータはプレーンなファイルであり、あなたのものです。Dóru にはアカウントもクラウドバックエンドもテレメトリもありません。*あなた*が AI プロバイダーを設定しない限り、何もどこにもアップロードされません——その場合でも、チャットで送信した内容だけがマシンの外に出ます。すべてをコンピューター上に保ちたい場合は、ローカルプロバイダー（Ollama、LM Studio）が完全にオフラインで動作します。
- バックアップするには：`.doru` ファイル（写真がある場合は隣の `media/` フォルダーも）をコピーします。それだけです。復元はそれをコピーして戻すだけです。
- ファイルはバージョン管理に適しています。安定したバイナリファイルなので、必要なら git にコミットできます。

## マシン間の同期

Dóru には組み込みの同期エンジンはありません——プロジェクトはプレーンなファイルであり、同期を保つのはあなたの仕事です：iCloud Drive、Dropbox、rclone、rsync、USB メモリなど、お好みの方法で。

1 つ注意点があります。`.doru` ファイルは SQLite データベースであり、**開いている**プロジェクトをファイル同期ツールでライブ同期すると、書き込み途中の状態でファイルがコピーされ、破損する可能性があります。安全な方法は、同期する前にプロジェクト（またはアプリ）を閉じることです。閉じたプロジェクトのコピーは常に安全です。
