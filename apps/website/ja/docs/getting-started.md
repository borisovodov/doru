# クイックスタート

1. Dóru を起動し、スタートページで **新しいプロジェクトを作成…**（または **プロジェクトを開く、または GEDCOM をインポート…**）をクリックします。
2. **作成**では保存場所と名前を尋ね、そこに `.doru` ファイルを作成します。**プロジェクトを開く、または GEDCOM をインポート**では、既存の `.doru` ファイル、または `.ged`/`.gdz` の GEDCOM ファイルを開きます——GEDCOM ファイルは、インポートした家系図を持つ新しい未保存のプロジェクトを開始します。後で `.doru` として保存してください。このファイルがプロジェクトそのものです——ファイル名がプロジェクト名になります：

```
My Family.doru      家系図そのもの（SQLite、アプリ ID が埋め込まれています）
media/              写真とスキャン画像。必要に応じて作成（任意）
```

3. データを入れます。新しい家系図には空のカードが 1 枚表示されます——クリックして名前を入力し、チェックマークで確定すると、最初の人物がキャンバスに表示されます。どのカードからも同じ方法で子ども、配偶者、親を追加できます。GEDCOM ファイルは **プロジェクトを開く、または GEDCOM をインポート**（手順 2）から取り込みます。エクスポートするには **エクスポート** タブを開き、**GEDCOM 7.0**（`.ged`）または **GEDZIP**（`.gdz`、管理対象のメディアファイル付き）を選び、保存先を確認します。

各プロジェクトは**それぞれのウィンドウ**で開きます。人物、家系図エディター、設定はその中のタブとして開きます。**新しいウィンドウ**（`⌘⇧N`、Linux と Windows では `Ctrl+Shift+N`）は、現在のプロジェクトを閉じずに別のスタートページを開くので、GEDCOM ファイルをインポートしたり、2 つ目の家系図を並べて開いたりできます。最近使用したプロジェクトはスタートページに一覧表示され、開いていたプロジェクトのウィンドウは次回起動時に復元されます。`*.doru` ファイルをダブルクリックするか、`doru://open?path=/…/family.doru` リンクを開くと、実行中のアプリで開きます。

## リンクからプロジェクトを開く

アプリは `doru://` URL スキームを登録しているため、アプリがまだ実行されていなくても、`doru://open?path=…` リンクでプロジェクトを開けます（`.ged`/`.gdz` の場合はファイルをインポートします）：

- パスは**絶対パスで URL エンコード**されている必要があります（スペースは `%20` など）。例：`doru://open?path=%2FUsers%2Fyou%2FFamily.doru`。
- アプリが実行されていない場合、リンクはアプリを起動し、すぐにプロジェクトを開きます。
- アプリがすでに実行されている場合、プロジェクトは実行中のインスタンスで開きます——2 つ目のインスタンスは起動されず、既存のウィンドウにフォーカスが移ります。
- リンクは、アプリが直接開けるファイル形式でのみ機能します：`.doru` プロジェクトと `.ged`/`.gdz` GEDCOM ファイルです。

macOS では `open "doru://open?path=…"` でターミナルや他のアプリからリンクを送れます。Linux では `xdg-open` が同じ役割を果たします。
