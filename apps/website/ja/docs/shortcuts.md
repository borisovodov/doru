# キーボードショートカット

Dóru は一般的なエディターの慣習に従います。macOS ではショートカットに ⌘ を、Linux と Windows では Ctrl を使用します。Shift と Alt/Option（⌥）はどこでも同じです。ショートカットの組み合わせ（⌘/Ctrl/Alt を含む）は、テキストフィールドやチャット入力欄を含むどこからでも機能します。通常の文字入力がショートカットを発動することはありません。

## プロジェクト

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 新しいプロジェクト… | `⌘N` | `Ctrl+N` |
| 新しいウィンドウ | `⌘⇧N` | `Ctrl+Shift+N` |
| プロジェクトを開く、または GEDCOM をインポート… | `⌘O` | `Ctrl+O` |
| 保存 | `⌘S` | `Ctrl+S` |
| GEDCOM をエクスポート… | `⌘⇧E` | `Ctrl+Shift+E` |
| 設定を開く | `⌘,` | `Ctrl+,` |

## ビュー

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 検索サイドバーを開く | `⌘⇧F` | `Ctrl+Shift+F` |

ショートカットは検索サイドバーを開き、クエリフィールドにカーソルを置いてすぐ入力できるようにします。

## タブ

| 操作 | macOS | Linux / Windows |
|---|---|---|
| タブを閉じる | `⌘W` | `Ctrl+W` |
| 次のタブ | `⌘⇧]` | `Ctrl+Tab` |
| 前のタブ | `⌘⇧[` | `Ctrl+Shift+Tab` |
| タブ 1〜9 に切り替え | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

タブの切り替えは端で折り返します。`⌘9`（`Ctrl+9`）は、開いているタブが 9 つ未満でも常に最後のタブにジャンプします。

## 編集

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 元に戻す | `⌘Z` | `Ctrl+Z` |
| やり直す | `⌘⇧Z` | `Ctrl+Shift+Z` |

キャンバス上のすべての操作——人物とその家族リンクの追加を含む——は 1 つの元に戻せるステップです。AI エージェントによる編集も元に戻せます。

## パネル

| 操作 | macOS | Linux / Windows |
|---|---|---|
| チャットパネルの表示切り替え | `⌘⌥B` | `Ctrl+Alt+B` |

## 入力中

入力欄の中では、いくつかのキーが特別に動作します：

- **チャット**：`Enter` でメッセージを送信します。
- **家系図の検索**：`Esc` で検索ボックスをクリアします。
- **人物エディター**：メモ欄で `Enter` を押すと、入力したメモが追加されます。

## 標準メニューのショートカット

ファイル／編集／表示／ウィンドウメニューには、プラットフォーム標準のアクセラレーターが用意されています：コピー、切り取り、貼り付け、すべて選択。拡大、縮小、ズームのリセット。全画面表示。再読み込みと開発者ツール。最小化、ウィンドウを閉じる、終了。これらはお使いのオペレーティングシステムの慣習に従うため、ここには記載しません。

## チートシート

すべてのタブを閉じると、空のエディターに 5 つのショートカットのサンプルが入れ替わりで表示され、思い出させる役割を果たします。タブを開いて閉じると、別のセットが表示されます。

## メモ

**プロジェクトを開く、または GEDCOM をインポート…** から `.ged`/`.gdz` ファイルを開くと、家系図が新しい未保存プロジェクトにインポートされます。エクスポートは **エクスポート** タブで行い、GEDCOM 7.0 と GEDZIP を提供しています（[クイックスタート](getting-started.md)を参照）。
