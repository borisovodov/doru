# AI とエージェント

## アプリ内チャット

チャットパネルはウィンドウの下部にあります。質問を入力すると、エージェントは組み込みツールを使って家系図を読み取り、編集できます：`tree_query`、`tree_get`、`tree_stats`、`tree_edit`、`tree_add_relative`、`sources_add`、`notes_write`。

会話は **チャットセッション** として保存されます。チャットパネルのヘッダーにセッションが一覧表示され、切り替え、新しいチャットの開始、削除ができます。セッションはプロジェクトごとにアプリのデータディレクトリに保存され（`.doru` ファイル内ではありません）、タイトルは最初のメッセージから作られ、すべてアプリの再起動後も残ります。各返信にはコピーボタンがあり、生の Markdown をシステムのクリップボードにコピーします。

プロバイダーは `settings.json` の `ai` セクションで設定します（[設定](settings.md)を参照）：

- **プロバイダーのプリセット**：Ollama、LM Studio、カスタムの OpenAI 互換エンドポイント、または ACP エージェント。クラウドのプリセットは統合の再構築に合わせて 1 つずつ復活します。ID は `"provider"` に設定します。各プリセットはデフォルトのベース URL を提供し、モデルは設定ウィザードで選択します——ローカルエンドポイントではプロバイダーから取得し、クラウドプリセットでは同梱のカタログから選択します。各プロバイダーは独自の設定（モデル、ベース URL、推論、キー）を `"providers"` の下に保持し、プロバイダーを切り替えるとそれぞれの保存済み設定が復元されます。
- **API キー** はアプリのデータディレクトリにある `secrets.json`（モード 0600）にプロバイダー ID をキーとして保存されます。キーが設定ファイルに表示されることはありません。

## Dóru AI（オフラインアシスタント）

デフォルトのプロバイダーは **Dóru AI** です。これは完全にあなたのコンピューター上で動作するローカルアシスタントです。AI 設定で一度ダウンロードしてください（単一ファイル、約 3 GB）。その後はアカウントもインターネット接続もなしでチャットが機能します。新規インストールではデフォルトで選択され、少なくとも 8 GB の RAM が必要です。

ダウンロードされるモデルは Qwen3.5-4B（Q4_K_M 量子化 GGUF、Apache-2.0 ライセンス——[モデルカード](https://huggingface.co/Qwen/Qwen3.5-4B)を参照）です。重みはアプリのマニフェストで SHA-256 により固定され、ダウンロードのたびに検証されます。

## ACP エージェント

Agent Client Protocol を話すエージェント（Zed スタイルのエージェント）と対話するには、`"ai": { "provider": "acp", "providers": { "acp": { "command": "…", "args": [] } } }` を設定します。Dóru はプロジェクトを MCP サーバーとしてエージェントに渡すため、エージェントは組み込みチャットと同じように家系図を照会および編集できます。

## MCP サーバーとしての Dóru

任意の MCP クライアント——Claude Desktop、Cursor、コーディングエージェント——が家系図を扱えます。Dóru をサーバーモードで実行し、`.doru` ファイルを指定します：

```sh
doru --mcp-server /absolute/path/to/family.doru
```

Claude Desktop の設定例（`Claude → Settings → Developer → Edit Config`）：

```json
{
  "mcpServers": {
    "doru": {
      "command": "/Applications/Doru.app/Contents/MacOS/doru",
      "args": ["--mcp-server", "/Users/you/FamilyHistory/family.doru"]
    }
  }
}
```

Linux AppImage：AppImage ファイルへのパス。Windows：`"command": "C:\\Program Files\\Doru\\doru.exe"`。ツール名は UI の言語に関係なく英語のままです。

サーバーは **ヘッドレスでステートレス** です。ウィンドウも Dock アイコンもチャットセッションもなく、家系図ファイルを直接読み書きし、クライアントが切断すると終了します。任意の数のクライアントが同じファイルを同時に指定できます（Claude Desktop、Cursor、複数のコーディングエージェント）。同時書き込みは安全にキューに入れられます。クライアントがサーバーを起動できない場合は、ターミナルでコマンドを実行してください——ヘルパーは問題を stderr に記録し、一時プロファイルは終了時に破棄されます。

## プロンプト例

- *「1850 年より前に生まれた全員を見つけて、その資料を一覧表示して。」*
- *「1923 年頃に生まれた Ivan Ivanov を、Petr と Maria の子どもとして追加して。」*
- *「Anna について、1901 年の国勢調査に関する調査メモを書いて。」*
- *「両親の死亡後に生まれた人物がいないか、家系図を確認して。」*
