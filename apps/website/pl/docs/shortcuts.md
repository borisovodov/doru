# Skróty klawiszowe

Dóru stosuje zwykłe konwencje edytorów: na macOS skróty używają ⌘, na Linuksie
i Windowsie Ctrl; Shift i Alt/Option (⌥) są wszędzie takie same. Kombinacje
skrótów (z ⌘/Ctrl/Alt) działają z dowolnego miejsca, także w polach tekstowych i
polu czatu; samo pisanie nigdy nie uruchamia skrótu.

## Projekty

| Działanie | macOS | Linux / Windows |
|---|---|---|
| Nowy projekt… | `⌘N` | `Ctrl+N` |
| Nowe okno | `⌘⇧N` | `Ctrl+Shift+N` |
| Otwórz projekt lub zaimportuj GEDCOM… | `⌘O` | `Ctrl+O` |
| Zapisz | `⌘S` | `Ctrl+S` |
| Eksportuj GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Otwórz ustawienia | `⌘,` | `Ctrl+,` |

## Widoki

| Działanie | macOS | Linux / Windows |
|---|---|---|
| Otwórz pasek boczny Szukaj | `⌘⇧F` | `Ctrl+Shift+F` |

Skrót otwiera pasek boczny Szukaj i umieszcza kursor w polu wyszukiwania,
gotowy do wpisania tekstu.

## Karty

| Działanie | macOS | Linux / Windows |
|---|---|---|
| Zamknij kartę | `⌘W` | `Ctrl+W` |
| Następna karta | `⌘⇧]` | `Ctrl+Tab` |
| Poprzednia karta | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Przełącz na kartę 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Przełączanie kart działa cyklicznie: po ostatniej karcie następuje pierwsza.
`⌘9` (`Ctrl+9`) zawsze przeskakuje do ostatniej karty, nawet gdy otwartych jest
mniej niż dziewięć.

## Edycja

| Działanie | macOS | Linux / Windows |
|---|---|---|
| Cofnij | `⌘Z` | `Ctrl+Z` |
| Ponów | `⌘⇧Z` | `Ctrl+Shift+Z` |

Każda akcja na płótnie — w tym dodanie osoby wraz z jej powiązaniem rodzinnym —
to jeden krok możliwy do cofnięcia; zmiany dokonane przez agentów AI również
można cofnąć.

## Panele

| Działanie | macOS | Linux / Windows |
|---|---|---|
| Przełącz panel czatu | `⌘⌥B` | `Ctrl+Alt+B` |

## Podczas pisania

Niektóre klawisze zachowują się w polach wejściowych w specjalny sposób:

- **Czat**: `Enter` wysyła wiadomość.
- **Wyszukiwanie w drzewie**: `Esc` czyści pole wyszukiwania.
- **Edytor osoby**: `Enter` w polu notatek dodaje wpisaną notatkę.

## Standardowe skróty menu

Menu Plik/Edycja/Widok/Okno zawierają standardowe akceleratory platformy:
kopiuj, wytnij, wklej i zaznacz wszystko; powiększ, pomniejsz i resetuj
powiększenie; pełny ekran; odśwież i narzędzia programistyczne; minimalizuj,
zamknij okno i zakończ. Są one zgodne z konwencjami Twojego systemu
operacyjnego i nie są tu wymienione.

## Ściągawka

Przy wszystkich zamkniętych kartach pusty edytor pokazuje rotacyjną próbkę
pięciu skrótów jako przypomnienie; zamknij i otwórz kartę ponownie, aby
zobaczyć inny zestaw.

## Uwagi

Otwarcie pliku `.ged`/`.gdz` przez **Otwórz projekt lub zaimportuj GEDCOM…**
importuje drzewo do nowego, jeszcze niezapisanego projektu. Eksport odbywa się
na karcie **Eksportuj GEDCOM**, która oferuje GEDCOM 7.0 i GEDZIP (zobacz
[Szybki start](getting-started.md)).
