# Atalhos de teclado

O Dóru segue as convenções usuais de editores: no macOS, os atalhos usam ⌘; no
Linux e no Windows, Ctrl; Shift e Alt/Option (⌥) são iguais em todos os
lugares. As combinações de atalhos (com ⌘/Ctrl/Alt) funcionam de qualquer
lugar, inclusive nos campos de texto e na entrada do chat; a digitação simples
nunca dispara um atalho.

## Projetos

| Ação | macOS | Linux / Windows |
|---|---|---|
| Novo projeto… | `⌘N` | `Ctrl+N` |
| Nova janela | `⌘⇧N` | `Ctrl+Shift+N` |
| Abrir projeto ou importar GEDCOM… | `⌘O` | `Ctrl+O` |
| Salvar | `⌘S` | `Ctrl+S` |
| Exportar GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Abrir configurações | `⌘,` | `Ctrl+,` |

## Visualizações

| Ação | macOS | Linux / Windows |
|---|---|---|
| Abrir a barra lateral Pesquisar | `⌘⇧F` | `Ctrl+Shift+F` |

O atalho abre a barra lateral Pesquisar e posiciona o cursor no campo de
consulta, pronto para digitar.

## Abas

| Ação | macOS | Linux / Windows |
|---|---|---|
| Fechar aba | `⌘W` | `Ctrl+W` |
| Próxima aba | `⌘⇧]` | `Ctrl+Tab` |
| Aba anterior | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Mudar para a aba 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

A troca de abas dá a volta ao chegar às extremidades. `⌘9` (`Ctrl+9`) sempre
salta para a última aba, mesmo quando há menos de nove abertas.

## Edição

| Ação | macOS | Linux / Windows |
|---|---|---|
| Desfazer | `⌘Z` | `Ctrl+Z` |
| Refazer | `⌘⇧Z` | `Ctrl+Shift+Z` |

Cada ação na tela — inclusive adicionar uma pessoa junto com seu vínculo
familiar — é uma única etapa que pode ser desfeita; edições feitas por agentes
de IA também podem ser desfeitas.

## Painéis

| Ação | macOS | Linux / Windows |
|---|---|---|
| Alternar o painel de chat | `⌘⌥B` | `Ctrl+Alt+B` |

## Ao digitar

Algumas teclas se comportam de forma especial dentro dos campos:

- **Chat**: `Enter` envia a mensagem.
- **Pesquisa na árvore**: `Esc` limpa a caixa de pesquisa.
- **Editor de pessoa**: `Enter` na caixa de notas adiciona a nota digitada.

## Atalhos padrão dos menus

Os menus Arquivo/Editar/Exibir/Janela trazem os aceleradores padrão da
plataforma: copiar, recortar, colar e selecionar tudo; ampliar, reduzir e
redefinir o zoom; tela cheia; recarregar e ferramentas do desenvolvedor;
minimizar, fechar janela e sair. Eles seguem as convenções do seu sistema
operacional e não estão listados aqui.

## Folha de consulta

Com todas as abas fechadas, o editor vazio mostra uma amostra rotativa de cinco
atalhos como lembrete; abra e feche uma aba para ver outro conjunto.

## Notas

Abrir um arquivo `.ged`/`.gdz` por **Abrir projeto ou importar GEDCOM…**
importa a árvore para um novo projeto ainda não salvo. A exportação acontece na
aba **Exportar GEDCOM**, que oferece GEDCOM 7.0 e GEDZIP (veja [Início
rápido](getting-started.md)).
