# Συντομεύσεις πληκτρολογίου

Το Dóru ακολουθεί τις συνήθεις συμβάσεις των επεξεργαστών: σε macOS οι συντομεύσεις χρησιμοποιούν ⌘, σε Linux και Windows Ctrl· τα Shift και Alt/Option (⌥) είναι τα ίδια παντού. Οι συνδυασμοί συντομεύσεων (με ⌘/Ctrl/Alt) λειτουργούν από οπουδήποτε, συμπεριλαμβανομένων των πεδίων κειμένου και της εισαγωγής συνομιλίας· η απλή πληκτρολόγηση δεν ενεργοποιεί ποτέ συντόμευση.

## Έργα

| Ενέργεια | macOS | Linux / Windows |
|---|---|---|
| Νέο έργο… | `⌘N` | `Ctrl+N` |
| Νέο παράθυρο | `⌘⇧N` | `Ctrl+Shift+N` |
| Άνοιγμα έργου ή εισαγωγή GEDCOM… | `⌘O` | `Ctrl+O` |
| Αποθήκευση | `⌘S` | `Ctrl+S` |
| Εξαγωγή GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Άνοιγμα ρυθμίσεων | `⌘,` | `Ctrl+,` |

## Προβολές

| Ενέργεια | macOS | Linux / Windows |
|---|---|---|
| Άνοιγμα της πλευρικής γραμμής αναζήτησης | `⌘⇧F` | `Ctrl+Shift+F` |

Η συντόμευση ανοίγει την πλευρική γραμμή αναζήτησης και τοποθετεί τον δείκτη στο πεδίο αναζήτησης, έτοιμο για πληκτρολόγηση.

## Καρτέλες

| Ενέργεια | macOS | Linux / Windows |
|---|---|---|
| Κλείσιμο καρτέλας | `⌘W` | `Ctrl+W` |
| Επόμενη καρτέλα | `⌘⇧]` | `Ctrl+Tab` |
| Προηγούμενη καρτέλα | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Μετάβαση στην καρτέλα 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Η εναλλαγή καρτελών κάνει κύκλο στα άκρα. Το `⌘9` (`Ctrl+9`) πηγαίνει πάντα στην τελευταία καρτέλα, ακόμη και όταν είναι ανοιχτές λιγότερες από εννέα.

## Επεξεργασία

| Ενέργεια | macOS | Linux / Windows |
|---|---|---|
| Αναίρεση | `⌘Z` | `Ctrl+Z` |
| Επανάληψη | `⌘⇧Z` | `Ctrl+Shift+Z` |

Κάθε ενέργεια στον καμβά — συμπεριλαμβανομένης της προσθήκης προσώπου μαζί με τον οικογενειακό του σύνδεσμο — είναι ένα βήμα που μπορεί να αναιρεθεί· οι επεξεργασίες από πράκτορες ΤΝ μπορούν επίσης να αναιρεθούν.

## Πλαίσια

| Ενέργεια | macOS | Linux / Windows |
|---|---|---|
| Εναλλαγή πλαισίου συνομιλίας | `⌘⌥B` | `Ctrl+Alt+B` |

## Κατά την πληκτρολόγηση

Μερικά πλήκτρα συμπεριφέρονται ειδικά μέσα στα πεδία εισαγωγής:

- **Συνομιλία**: το `Enter` στέλνει το μήνυμα.
- **Αναζήτηση δέντρου**: το `Esc` καθαρίζει το πεδίο αναζήτησης.
- **Επεξεργαστής προσώπου**: το `Enter` στο πλαίσιο σημειώσεων προσθέτει τη σημείωση που πληκτρολογήσατε.

## Τυπικές συντομεύσεις μενού

Τα μενού Αρχείο/Επεξεργασία/Προβολή/Παράθυρο παρέχουν τους τυπικούς επιταχυντές της πλατφόρμας: αντιγραφή, αποκοπή, επικόλληση και επιλογή όλων· μεγέθυνση, σμίκρυνση και επαναφορά ζουμ· πλήρης οθόνη· επαναφόρτωση και εργαλεία προγραμματιστή· ελαχιστοποίηση, κλείσιμο παραθύρου και έξοδος. Αυτά ακολουθούν τις συμβάσεις του λειτουργικού σας συστήματος και δεν αναφέρονται εδώ.

## Φύλλο αναφοράς

Με όλες τις καρτέλες κλειστές, ο κενός επεξεργαστής εμφανίζει ένα περιστρεφόμενο δείγμα πέντε συντομεύσεων ως υπενθύμιση· κλείστε και ανοίξτε ξανά μια καρτέλα για να δείτε άλλο σύνολο.

## Σημειώσεις

Το άνοιγμα αρχείου `.ged`/`.gdz` μέσω **Άνοιγμα έργου ή εισαγωγή GEDCOM…** εισάγει το δέντρο σε νέο, μη αποθηκευμένο ακόμη έργο. Η εξαγωγή γίνεται στην καρτέλα **Εξαγωγή**, που προσφέρει GEDCOM 7.0 και GEDZIP (βλ. [Γρήγορη εκκίνηση](getting-started.md)).
