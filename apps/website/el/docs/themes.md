# Θέματα

Η διεπαφή διαμορφώνεται εξ ολοκλήρου μέσω προσαρμοσμένων ιδιοτήτων CSS, που εφαρμόζονται σε επίπεδο εφαρμογής — ποτέ ανά έργο.

- **Ενσωματωμένο θέμα** — `doru`, ένα μόνο αρχείο παλέτας JSON στον κατάλογο `themes/` της εφαρμογής: ένα αρχείο ανά θέμα, χωρίς CSS. Το αρχείο περιέχει και τη `dark` και τη `light` παλέτα· η εμφάνιση του λειτουργικού συστήματος αποφασίζει ποια εφαρμόζεται — αλλάξτε το λειτουργικό σε φωτεινή λειτουργία και το Dóru ακολουθεί αμέσως. Το όνομα του αρχείου είναι το αναγνωριστικό του θέματος (`doru.json`)· το πεδίο `name` μέσα είναι το εμφανιζόμενο όνομα.
- Επιλέξτε το θέμα στο `settings.json` (βλ. [Ρυθμίσεις](settings.md)) με μία μόνο συμβολοσειρά, ή από τη σελίδα **Ρυθμίσεις** της εφαρμογής (αναπτυσσόμενο μενού Θέμα)· η επιλογή αποθηκεύεται στο `settings.json` και με τους δύο τρόπους.
- Τα `colors` της ενεργής παλέτας μετατρέπονται σε προσαρμοσμένες ιδιότητες CSS `--doru-*` κατά την εκκίνηση.

## Θέματα χρήστη

Τοποθετήστε ένα αρχείο `<id>.json` με παλέτες `dark` και `light` στον κατάλογο `themes` μέσα στον κατάλογο δεδομένων της εφαρμογής (το ίδιο μέρος όπου ζει το `settings.json` — βλ. [Ρυθμίσεις](settings.md)), και μετά επιλέξτε το με `"theme": "<id>"` στο `settings.json`. Επανεκκινήστε την εφαρμογή αφού προσθέσετε αρχείο για να αναγνωριστεί. Ο κατάλογος δημιουργείται στην πρώτη εκτέλεση· ένα θέμα χρήστη του οποίου το αναγνωριστικό ταιριάζει με ενσωματωμένο το αντικαθιστά. Ένα αρχείο θέματος που είναι κακοσχηματισμένο ή δεν ταιριάζει με το σχήμα παραλείπεται (καταγράφεται προειδοποίηση), όπως και ένα που λείπει, και δεν εμφανίζεται στη λίστα θεμάτων. Τα ενσωματωμένα θέματα φέρουν αναφορά `$schema` (`https://doru.family/theme.json`) — προσθέστε την ίδια γραμμή στο δικό σας αρχείο για αυτόματη συμπλήρωση και επικύρωση σε επεξεργαστές που κατανοούν JSON Schema.

Ενσωματωμένα θέματα, το καθένα με σκούρα και φωτεινή παλέτα:

| Αναγνωριστικό θέματος | Εμφανιζόμενο όνομα |
|---|---|
| `doru` (προεπιλογή) | Dóru |
| `one-dark` | One Dark |
| `github` | GitHub |
| `solarized` | Solarized |
| `gruvbox` | Gruvbox |
| `catppuccin` | Catppuccin |
| `ayu` | Ayu |
| `rose-pine` | Rosé Pine |
| `everforest` | Everforest |

Η προεπιλεγμένη παλέτα Dóru ακολουθεί το εικονίδιο της εφαρμογής: βαθύ δασικό πράσινο με ζεστούς τόνους χαρτιού. Η σκούρα παλέτα στρώνει επιφάνειες από έναν σχεδόν μαύρο καμβά με πράσινη απόχρωση σε ελαφρύτερο πλαίσιο και αναδυόμενα παράθυρα· η φωτεινή παλέτα χρησιμοποιεί ζεστό χαρτί και κρέμα.

Διαθέσιμες μεταβλητές:

| Μεταβλητή | Σημασία |
|---|---|
| `--doru-bg-canvas` | φόντο επεξεργαστή και λωρίδα καρτελών |
| `--doru-bg-chrome` | γραμμή δραστηριοτήτων, πλευρικές γραμμές, επιφάνεια πλαισίου |
| `--doru-bg-raised` | κάρτες, πλακίδια, το πεδίο συνομιλίας |
| `--doru-bg-popover` | μενού και επιλογείς |
| `--doru-bg-input` | κουμπιά, πεδία εισαγωγής, επιλογείς |
| `--doru-fg` / `--doru-fg-muted` / `--doru-fg-faint` | κύριο, θαμπό και αμυδρό κείμενο |
| `--doru-border` / `--doru-border-strong` | λεπτές γραμμές και ισχυρότερα περιγράμματα |
| `--doru-accent` / `--doru-accent-hover` / `--doru-accent-active` | τονισμός (δασικό/φασκόμηλο πράσινο) |
| `--doru-on-accent` | κείμενο στο φόντο τονισμού |
| `--doru-accent-alpha` | ημιδιαφανής τονισμός (πλακίδια, φυσαλίδες συνομιλίας) |
| `--doru-focus` | χρώμα δακτυλίου εστίασης |
| `--doru-overlay-hover` / `--doru-overlay-pressed` | επικαλύψεις αιώρησης/πάτησης |
| `--doru-success` / `--doru-warning` / `--doru-danger` / `--doru-info` | χρώματα κατάστασης |
| `--doru-radius-sm` / `--doru-radius-md` / `--doru-radius-lg` | ακτίνες 4 / 6 / 8 px |
| `--doru-control-height` | ύψος στοιχείου ελέγχου (28px) |
| `--doru-panel-gutter` | κενό μεταξύ πλαισίων και άκρου παραθύρου (4px) |
| `--doru-panel-radius` | ακτίνα γωνιών πλαισίου (8px) |
