# ΤΝ και πράκτορες

## Η ενσωματωμένη συνομιλία

Το πλαίσιο συνομιλίας βρίσκεται στο κάτω μέρος του παραθύρου. Πληκτρολογήστε μια ερώτηση και ο πράκτορας μπορεί να διαβάσει και να επεξεργαστεί το δέντρο χρησιμοποιώντας ενσωματωμένα εργαλεία: `tree_query`, `tree_get`, `tree_stats`, `tree_edit`, `tree_add_relative`, `sources_add`, `notes_write`.

Οι συνομιλίες αποθηκεύονται ως **σύνοδοι συνομιλίας**: η κεφαλίδα του πλαισίου συνομιλίας απαριθμεί τις συνόδους σας και μπορείτε να εναλλάσσεστε μεταξύ τους, να ξεκινήσετε νέα συνομιλία ή να τις διαγράψετε. Οι σύνοδοι αποθηκεύονται ανά έργο στον κατάλογο δεδομένων της εφαρμογής (όχι μέσα στο αρχείο `.doru`), ο τίτλος προέρχεται από το πρώτο σας μήνυμα και όλα επιβιώνουν από επανεκκινήσεις της εφαρμογής. Κάθε απάντηση έχει κουμπί αντιγραφής που τοποθετεί το ακατέργαστο markdown της στο πρόχειρο του συστήματος.

Ο πάροχος ρυθμίζεται στην ενότητα `ai` του `settings.json` (βλ. [Ρυθμίσεις](settings.md)):

- **Προεπιλογές παρόχων**: Ollama, LM Studio, προσαρμοσμένο τελικό σημείο συμβατό με OpenAI ή πράκτορας ACP. Οι προεπιλογές cloud επιστρέφουν μία μία καθώς οι ενσωματώσεις τους ξαναχτίζονται. Ορίστε το αναγνωριστικό στο `"provider"`· κάθε προεπιλογή παρέχει προεπιλεγμένο βασικό URL, ενώ το μοντέλο επιλέγεται στον οδηγό Ρυθμίσεων — ανακτάται από τον πάροχο για τοπικά τελικά σημεία, επιλέγεται από τον παρεχόμενο κατάλογο για προεπιλογές cloud. Κάθε πάροχος διατηρεί τη δική του διαμόρφωση (μοντέλο, βασικό URL, συλλογισμό, κλειδί) κάτω από το `"providers"` — η εναλλαγή παρόχου επαναφέρει τις αποθηκευμένες ρυθμίσεις καθενός.
- **Τα κλειδιά API** αποθηκεύονται στο `secrets.json` (λειτουργία 0600) στον κατάλογο δεδομένων της εφαρμογής, με κλειδί το αναγνωριστικό παρόχου. Το κλειδί δεν εμφανίζεται ποτέ στο αρχείο ρυθμίσεων.

## Dóru AI (βοηθός εκτός σύνδεσης)

Ο προεπιλεγμένος πάροχος είναι το **Dóru AI**: ένας τοπικός βοηθός που εκτελείται εξ ολοκλήρου στον υπολογιστή σας. Κατεβάστε το μία φορά στις ρυθμίσεις AI (ένα μόνο αρχείο, περίπου 3 GB)· μετά από αυτό η συνομιλία λειτουργεί χωρίς λογαριασμό και χωρίς σύνδεση στο διαδίκτυο. Είναι προεπιλεγμένο σε νέα εγκατάσταση και χρειάζεται τουλάχιστον 8 GB μνήμης RAM.

Το μοντέλο που λαμβάνεται είναι το Qwen3.5-4B (κβαντισμένο GGUF Q4_K_M, άδεια Apache-2.0 — βλ. [κάρτα μοντέλου](https://huggingface.co/Qwen/Qwen3.5-4B)). Τα βάρη σταθεροποιούνται με SHA-256 στο δηλωτικό της εφαρμογής και επαληθεύονται μετά από κάθε λήψη.

## Πράκτορες ACP

Ορίστε `"ai": { "provider": "acp", "providers": { "acp": { "command": "…", "args": [] } } }` για να μιλήσετε με πράκτορα που μιλά το Agent Client Protocol (πράκτορες τύπου Zed). Το Dóru περνά το έργο στον πράκτορα ως διακομιστή MCP, ώστε ο πράκτορας να μπορεί να αναζητά και να επεξεργάζεται το δέντρο ακριβώς όπως η ενσωματωμένη συνομιλία.

## Το Dóru ως διακομιστής MCP

Οποιοσδήποτε πελάτης MCP — Claude Desktop, Cursor, πράκτορες προγραμματισμού — μπορεί να δουλέψει με το δέντρο σας. Εκτελέστε το Dóru σε λειτουργία διακομιστή, δείχνοντας στο αρχείο `.doru`:

```sh
doru --mcp-server /absolute/path/to/family.doru
```

Παράδειγμα διαμόρφωσης Claude Desktop (`Claude → Settings → Developer → Edit Config`):

```json
{
  "mcpServers": {
    "doru": {
      "command": "/Applications/Doru.app/Contents/MacOS/doru",
      "args": ["--mcp-server", "/Users/you/FamilyHistory/family.doru"]
    }
  }
}
```

Linux AppImage: η διαδρομή προς το αρχείο AppImage. Windows: `"command": "C:\\Program Files\\Doru\\doru.exe"`. Τα ονόματα εργαλείων μένουν στα αγγλικά ανεξάρτητα από τη γλώσσα της διεπαφής.

Ο διακομιστής είναι **χωρίς διεπαφή και χωρίς κατάσταση**: χωρίς παράθυρο, χωρίς εικονίδιο στο dock, χωρίς συνόδους συνομιλίας — διαβάζει και επεξεργάζεται απευθείας το αρχείο δέντρου και εξέρχεται όταν ο πελάτης αποσυνδεθεί. Οποιοσδήποτε αριθμός πελατών μπορεί να δείχνει στο ίδιο αρχείο ταυτόχρονα (Claude Desktop, Cursor, αρκετοί πράκτορες προγραμματισμού)· οι ταυτόχρονες εγγραφές μπαίνουν σε ασφαλή ουρά. Αν ένας πελάτης δεν μπορεί να ξεκινήσει τον διακομιστή, εκτελέστε την εντολή σε τερματικό — το βοηθητικό πρόγραμμα καταγράφει τα προβλήματα στο stderr και το προσωρινό προφίλ του απορρίπτεται κατά την έξοδο.
