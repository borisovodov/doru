# 키보드 단축키

Dóru는 일반적인 편집기 관례를 따릅니다. macOS에서는 단축키에 ⌘을, Linux와 Windows에서는 Ctrl을 사용합니다. Shift와 Alt/Option(⌥)은 어디서나 같습니다. 단축키 조합(⌘/Ctrl/Alt 포함)은 텍스트 필드와 채팅 입력란을 포함한 어디서나 작동합니다. 일반 문자 입력은 절대 단축키를 실행하지 않습니다.

## 프로젝트

| 작업 | macOS | Linux / Windows |
|---|---|---|
| 새 프로젝트… | `⌘N` | `Ctrl+N` |
| 새 창 | `⌘⇧N` | `Ctrl+Shift+N` |
| 프로젝트 열기 또는 GEDCOM 가져오기… | `⌘O` | `Ctrl+O` |
| 저장 | `⌘S` | `Ctrl+S` |
| GEDCOM 내보내기… | `⌘⇧E` | `Ctrl+Shift+E` |
| 설정 열기 | `⌘,` | `Ctrl+,` |

## 보기

| 작업 | macOS | Linux / Windows |
|---|---|---|
| 검색 사이드바 열기 | `⌘⇧F` | `Ctrl+Shift+F` |

이 단축키는 검색 사이드바를 열고 쿼리 필드에 커서를 놓아 바로 입력할 수 있게 합니다.

## 탭

| 작업 | macOS | Linux / Windows |
|---|---|---|
| 탭 닫기 | `⌘W` | `Ctrl+W` |
| 다음 탭 | `⌘⇧]` | `Ctrl+Tab` |
| 이전 탭 | `⌘⇧[` | `Ctrl+Shift+Tab` |
| 1–9번 탭으로 전환 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

탭 전환은 끝에서 순환합니다. `⌘9`(`Ctrl+9`)는 탭이 9개 미만 열려 있어도 항상 마지막 탭으로 이동합니다.

## 편집

| 작업 | macOS | Linux / Windows |
|---|---|---|
| 실행 취소 | `⌘Z` | `Ctrl+Z` |
| 다시 실행 | `⌘⇧Z` | `Ctrl+Shift+Z` |

캔버스의 모든 작업——인물과 가족 링크를 함께 추가하는 것 포함——은 하나의 실행 취소 가능한 단계입니다. AI 에이전트가 한 편집도 취소할 수 있습니다.

## 패널

| 작업 | macOS | Linux / Windows |
|---|---|---|
| 채팅 패널 표시/숨기기 | `⌘⌥B` | `Ctrl+Alt+B` |

## 입력 중

입력란 안에서는 몇 가지 키가 특별하게 동작합니다:

- **채팅**: `Enter`로 메시지를 보냅니다.
- **가계도 검색**: `Esc`로 검색 상자를 지웁니다.
- **인물 편집기**: 메모 상자에서 `Enter`를 누르면 입력한 메모가 추가됩니다.

## 표준 메뉴 단축키

파일/편집/보기/창 메뉴에는 플랫폼 표준 액셀러레이터가 있습니다: 복사, 잘라내기, 붙여넣기, 모두 선택; 확대, 축소, 확대/축소 초기화; 전체 화면; 다시 로드 및 개발자 도구; 최소화, 창 닫기, 종료. 이들은 운영 체제의 관례를 따르므로 여기에 나열하지 않습니다.

## 치트 시트

모든 탭을 닫으면 빈 편집기에 다섯 가지 단축키 샘플이 돌아가며 표시되어 알림 역할을 합니다. 탭을 열었다가 닫으면 다른 세트가 표시됩니다.

## 참고

**프로젝트 열기 또는 GEDCOM 가져오기…** 로 `.ged`/`.gdz` 파일을 열면 가계도가 새 미저장 프로젝트로 가져옵니다. 내보내기는 **내보내기** 탭에서 이루어지며 GEDCOM 7.0과 GEDZIP을 제공합니다([빠른 시작](getting-started.md) 참조).
