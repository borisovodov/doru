# 데이터와 백업

- 데이터는 평범한 파일이며, 계속 여러분의 것입니다. Dóru에는 계정도, 클라우드 백엔드도, 텔레메트리도 없습니다. *여러분*이 AI 제공자를 구성하지 않는 한 아무것도 어디에도 업로드되지 않으며——그 경우에도 채팅에서 보낸 내용만 컴퓨터를 떠납니다. 모든 것을 컴퓨터에 보관하고 싶다면 로컬 제공자(Ollama, LM Studio)가 완전히 오프라인으로 작동합니다.
- 백업하려면: `.doru` 파일(사진이 있다면 옆의 `media/` 폴더도)을 복사하세요. 그게 전부입니다. 복원은 그것을 다시 복사하면 됩니다.
- 파일은 버전 관리에 적합합니다. 안정적인 바이너리 파일이므로 원한다면 git에 커밋하세요.

## 컴퓨터 간 동기화

Dóru에는 내장 동기화 엔진이 없습니다——프로젝트는 평범한 파일이며, 동기화를 유지하는 것은 여러분의 몫입니다: iCloud Drive, Dropbox, rclone, rsync, USB 스틱 등 원하는 무엇이든.

한 가지 주의할 점: `.doru` 파일은 SQLite 데이터베이스이므로 **열려 있는** 프로젝트를 파일 동기화 도구로 라이브 동기화하면 파일이 반쯤 기록된 상태로 복사되어 손상될 수 있습니다. 안전한 방법은 동기화하기 전에 프로젝트(또는 앱)를 닫는 것입니다. 닫힌 프로젝트를 복사하는 것은 항상 안전합니다.
