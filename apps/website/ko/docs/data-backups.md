# 데이터와 백업

- 데이터는 평범한 파일이며, 계속 여러분의 것입니다. Dóru에는 계정도, 클라우드 백엔드도, 텔레메트리도 없습니다. *여러분*이 원격 AI 제공자를 구성하지 않는 한 아무것도 어디에도 업로드되지 않으며——그 경우에도 채팅 메시지와 어시스턴트가 도구를 통해 가져오는 가계도 데이터가 해당 제공자에게 전송됩니다. 모든 것을 컴퓨터에 보관하고 싶다면 로컬 제공자(Ollama, LM Studio)가 완전히 오프라인으로 작동합니다.
- 백업하려면: 프로젝트에 쓸 수 있는 모든 프로세스를 중지하세요——Dóru에서 프로젝트를 닫고 MCP 클라이언트나 다른 도구도 중지한 다음——`.doru` 파일(사진이 있다면 옆의 `media/` 폴더도)을 복사하세요. 그게 전부입니다. 복원은 프로젝트를 닫고 다른 쓰기 프로세스가 없는 상태에서 `.doru` 파일과 `media/` 폴더를 모두 다시 복사하는 것입니다. 충돌 후에는 Dóru에서 프로젝트를 한 번 열어 SQLite가 남아 있는 저널을 복구할 수 있게 한 다음, 복사하거나 복원하기 전에 닫으세요.
- 채팅 세션은 `.doru` 파일이 아니라 앱 데이터 디렉터리에 저장됩니다. 필요하면 별도로 백업하세요.
- 파일은 버전 관리에 적합합니다. 안정적인 바이너리 파일이므로 원한다면 git에 커밋하세요.

## 컴퓨터 간 동기화

Dóru에는 내장 동기화 엔진이 없습니다——프로젝트는 평범한 파일이며, 동기화를 유지하는 것은 여러분의 몫입니다: iCloud Drive, Dropbox, rclone, rsync, USB 스틱 등 원하는 무엇이든.

한 가지 주의할 점: `.doru` 파일은 SQLite 데이터베이스이므로 **열려 있는** 프로젝트를 파일 동기화 도구로 라이브 동기화하면 파일이 반쯤 기록된 상태로 복사되어 손상될 수 있습니다. 안전한 방법은 동기화하기 전에 프로젝트(또는 앱)를 닫고 다른 쓰기 프로세스를 모두 중지하는 것입니다. 올바르게 닫혔고 다른 쓰기 프로세스가 없는 프로젝트는 안전하게 복사할 수 있습니다. 충돌 후에는 Dóru에서 프로젝트를 한 번 열어 SQLite가 남아 있는 저널을 롤백할 수 있게 한 다음, 복사하기 전에 닫으세요.
