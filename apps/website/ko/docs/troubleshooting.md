# 문제 해결

- **이전 빌드의 `.doru` 프로젝트가 열리지 않음** — 1.0 이전에는 프로젝트 스키마가 마이그레이션 없이 변경되므로 다른 빌드에서 작성한 파일을 이해하지 못합니다. 프로젝트를 만든 빌드에서 열고 GEDCOM을 내보낸 다음, 그 파일을 이 빌드로 가져오세요.
- **"AI 제공자가 구성되지 않았습니다"** — 설정(왼쪽 막대의 톱니바퀴 아이콘)을 열고 제공자를 선택한 뒤 마법사를 따르세요: 모델 목록을 가져오거나(또는 모델을 선택), 필요한 경우 키를 저장합니다.
- **Ollama 연결 실패** — Ollama 프리셋(기본 URL `http://localhost:11434/v1`)을 선택하세요. API 키는 필요하지 않습니다. "제공자에서 모델 가져오기"를 누르세요——제공자에 연결할 수 없다고 표시되면 Ollama가 로컬에서 실행 중인지 확인하세요.
