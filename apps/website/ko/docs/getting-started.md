# 빠른 시작

1. Dóru를 실행하고 시작 페이지에서 **새 프로젝트 만들기…**(또는 **프로젝트 열기 또는 GEDCOM 가져오기…**)를 클릭합니다.
2. **만들기**는 위치와 이름을 묻고 그곳에 `.doru` 파일을 만듭니다. **프로젝트 열기 또는 GEDCOM 가져오기**는 기존 `.doru` 파일이나 `.ged`/`.gdz` GEDCOM 파일을 엽니다——GEDCOM 파일은 가져온 가계도로 새 미저장 프로젝트를 시작하므로 나중에 `.doru`로 저장하세요. 파일 자체가 프로젝트입니다——파일 이름이 프로젝트 이름이 됩니다:

```
My Family.doru      가계도 자체(SQLite, 앱 ID가 새겨져 있음)
media/              사진과 스캔 이미지, 필요할 때 생성(선택 사항)
```

3. 데이터를 넣습니다. 새 가계도에는 빈 카드 하나가 표시됩니다——클릭하고 이름을 입력한 뒤 체크 표시로 확인하면 첫 인물이 캔버스에 나타납니다. 모든 카드에서 같은 방식으로 자녀, 배우자, 부모를 추가할 수 있습니다. GEDCOM 파일은 **프로젝트 열기 또는 GEDCOM 가져오기**(2단계)를 통해 들어옵니다. 내보내려면 **내보내기** 탭을 열고 **GEDCOM 7.0**(`.ged`) 또는 **GEDZIP**(`.gdz`, 관리되는 미디어 파일 포함)을 선택한 뒤 저장 위치를 확인합니다.

각 프로젝트는 **자체 창**에서 열립니다. 인물, 가계도 편집기, 설정은 그 안의 탭으로 열립니다. **새 창**(`⌘⇧N`, Linux와 Windows에서는 `Ctrl+Shift+N`)은 현재 프로젝트를 닫지 않고 또 다른 시작 페이지를 열어 주므로 GEDCOM 파일을 가져오거나 두 번째 가계도를 나란히 열 수 있습니다. 최근 사용한 프로젝트는 시작 페이지에 나열되며, 열려 있던 프로젝트 창은 다음 실행 시 복원됩니다. `*.doru` 파일을 더블클릭하거나 `doru://open?path=/…/family.doru` 링크를 열면 실행 중인 앱에서 열립니다.

## 링크에서 프로젝트 열기

앱은 `doru://` URL 체계를 등록하므로 앱이 아직 실행되지 않았더라도 `doru://open?path=…` 링크로 프로젝트를 엽니다(`.ged`/`.gdz`의 경우 파일을 가져옵니다):

- 경로는 **절대 경로이면서 URL 인코딩**되어야 합니다(공백은 `%20` 등). 예: `doru://open?path=%2FUsers%2Fyou%2FFamily.doru`.
- 앱이 실행 중이 아니면 링크가 앱을 실행하고 프로젝트를 바로 엽니다.
- 앱이 이미 실행 중이면 프로젝트는 실행 중인 인스턴스에서 열립니다——두 번째 인스턴스는 시작되지 않고 기존 창에 포커스가 맞춰집니다.
- 링크는 앱이 직접 여는 파일 형식에만 작동합니다: `.doru` 프로젝트와 `.ged`/`.gdz` GEDCOM 파일.

macOS에서는 `open "doru://open?path=…"`로 터미널이나 다른 앱에서 링크를 보낼 수 있고, Linux에서는 `xdg-open`이 같은 역할을 합니다.
