# 使用家譜

家譜以互動式畫布形式開啟。以下操作都在畫布上完成；人物清單位於左側活動列的 **人物** 檢視中。

## 導覽

- 拖曳背景進行**平移**，使用滾輪或觸控板**縮放**；縮放按鈕位於畫布角落。
- 按兩下人物卡片可**重新聚焦**到該人物。工具列會保留歷史記錄：上一頁/下一頁箭頭和麵包屑路徑。
- **圖表**：在工具列中切換 *祖先*、*後代*、*沙漏* 和 *家庭* 檢視。家庭檢視顯示焦點夫婦、他們的子女以及雙方的父母。
- **搜尋**：在工具列搜尋框中輸入姓名，選擇結果即可跳轉到該人物。
- **摺疊**卡片上的箭頭可摺疊分支（也可從工具列摺疊/展開所有分支）。

## 卡片

每張卡片顯示姓名首字母頭像、姓名、生卒年份（已故人物帶 †），以及統計筆記、來源和媒體數量的小徽章。左邊緣在祖先圖中標示父系（藍色）和母系（粉紅色），強調邊框標示焦點人物。

## 編輯

選擇卡片會顯示操作工具列：

- **新增子女 / 配偶 / 父母** — 人物旁邊會出現一張新的空白卡片；直接在卡片中輸入姓名並用對勾確認（叉號則捨棄）。
- **編輯** — 以分頁形式開啟完整的人物編輯器：姓名、性別、出生/死亡日期及品質標記（*精確 / 大約 / 之前 / 之後*）和自由文字形式（例如無法對應到公曆的曆法日期「23 Nivôse」）、家庭、事件、來源、筆記和媒體。
- **刪除** — 將人物從家譜和所有家庭中移除。
- **變更父母**：將卡片拖曳到另一個人物的卡片上，可將拖曳的人物作為子女移入該家庭（拖曳時有效目標會醒目顯示）。

新建（空白）家譜會顯示一張空白卡片：按一下它，輸入姓名，用對勾確認，第一個人就會出現在畫布上。之後，從卡片本身逐步擴展家譜。

## 家庭

在完整的人物編輯器中，新增父母、伴侶或子女。輸入姓名以選擇現有人物；標籤會顯示每個家庭的成員。從家庭中移除人物或刪除家庭都只需按一下。

## 來源與筆記

- **來源**：為人物附加來源（含標題和作者），或重複使用現有來源。每次附加都是一條引用，可以移除。
- **筆記**：附加到人物的自由形式研究筆記。一則筆記可以附加到多筆記錄：在另一筆記錄的「筆記」區段使用 **附加現有筆記**，然後選擇編輯時是在所有地方更新共用文字，還是僅更新目前記錄。**從此記錄分離** 會移除一個連結；**在所有地方刪除** 會刪除該筆記。
- 事件和姓名在人物編輯器內各自擁有來源、筆記、標籤、識別碼、聯絡方式和限制區段。

## 地址

**來源** 檢視有一個 **地址** 區段。用它來建立、編輯和刪除獨立地址。被事件、存放庫或提交者使用的地址會顯示使用次數；刪除地址會將其從這些記錄中分離。事件的地址選擇器還提供 **新地址** 和 **編輯地址** 操作，可就地編輯地址。

## 任務

任務除了排定日期和提醒日期外，還有建立日期和結束日期。每個編輯器都有一個 **任務** 區段：在那裡新增任務後，它會自動連結到該記錄。事件、姓名、引文和筆記在其附加面板中各自帶有「任務」區段。**關聯至** 可將任務連結到家譜中的任何記錄——人物、家庭、事件、姓名、來源、引文、筆記、媒體檔案、地點、存放庫、提交者、地址、著作，甚至另一個任務；留空則為獨立任務。

著作、任務、地址、關聯以及家庭的伴侶/子女連結擁有與主要實體分頁相同的筆記、來源、標籤、識別碼、聯絡方式、限制、貢獻者和任務區段。

## 媒體

照片是專案旁邊 `media/` 資料夾中的普通檔案。可從人物、家庭、來源、地點、存放庫、提交者、著作、任務或地址新增。媒體區段還允許將現有記錄附加到另一個目標。按一下預覽可開啟媒體分頁，在其中編輯標題、管理檔案，並編輯連結中繼資料，如說明文字、順序、主要旗標和排除旗標。

一筆媒體記錄可以連結到多個目標。**從此記錄分離** 會移除一個連結；**刪除媒體** 會刪除該記錄及其檔案副本。不再有任何連結的記錄會被自動刪除。

## 排序

順序重要的清單——姓名、家庭伴侶和子女、地點名稱、地址行、事件參與者和範本欄位——都有上移/下移控制項。順序以列位置儲存。
