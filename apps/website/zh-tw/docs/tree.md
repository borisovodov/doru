# 使用家譜

家譜以互動式畫布形式開啟。以下操作都在畫布上完成；人物清單位於左側活動列的 **人物** 檢視中。

## 導覽

- 拖曳背景進行**平移**，使用滾輪或觸控板**縮放**；縮放按鈕位於畫布角落。
- 按兩下人物卡片可**重新聚焦**到該人物。視窗上的「上一頁/下一頁」按鈕可返回先前的分頁和家譜位置。
- **祖先和後代**始終一起顯示：焦點上方是父母和祖父母，下方是子女。
- **搜尋**：在工具列搜尋框中輸入姓名，選擇結果即可跳轉到該人物。

## 卡片

每張卡片顯示姓名首字母頭像、姓名、生卒年份（已故人物帶 †），以及統計筆記、來源和媒體數量的小徽章。左邊緣在祖先圖中標示父系（藍色）和母系（粉紅色），強調邊框標示焦點人物。

## 編輯

選擇卡片會顯示操作工具列：

- **新增子女 / 配偶 / 父母** — 人物旁邊會出現一張新的空白卡片；直接在卡片中輸入姓名並用對勾確認（叉號則捨棄）。
- **編輯** — 以分頁形式開啟完整的人物編輯器：姓名、性別、出生/死亡日期及品質標記（*精確 / 大約 / 之前 / 之後*）和自由文字形式（例如無法對應到公曆的曆法日期「23 Nivôse」）、家庭、事件、來源、筆記和媒體。
- **刪除** — 將人物從家譜和所有家庭中移除。

新建（空白）家譜會顯示一張空白卡片：按一下它，輸入姓名，用對勾確認，第一個人就會出現在畫布上。之後，從卡片本身逐步擴展家譜。

## 家庭

在完整的人物編輯器中，新增父母、伴侶或子女。輸入姓名以選擇現有人物；標籤會顯示每個家庭的成員。從家庭中移除人物或刪除家庭都只需按一下。

## 來源與筆記

- **來源**：為人物附加來源（含標題和作者），或重複使用現有來源。每次附加都是一條引用，可以移除。
- **筆記**：附加到人物的自由形式研究筆記。每則筆記只屬於一筆記錄：在該記錄的「筆記」區段新增、編輯或刪除。匯入的 GEDCOM 檔案中的共用筆記會複製到參照它的每筆記錄。

## 地址

**來源** 檢視有一個 **地址** 區段。用它來建立、編輯和刪除獨立地址。被事件、存放庫或提交者使用的地址會顯示使用次數；刪除地址會將其從這些記錄中分離。事件的地址選擇器還提供 **新地址** 和 **編輯地址** 操作，可就地編輯地址。

## 任務

任務有建立日期和提醒日期。關閉任務只會改變其狀態，不會另外儲存完成日期。大多數編輯器都有一個 **任務** 區段：在那裡新增任務後，它會自動連結到該記錄。任務編輯器與提交者編輯器是例外：任務卡片保留「筆記」和「媒體」，提交者卡片沒有「任務」區段，媒體連結不能作為任務的目標。事件、姓名和引文在其附加面板中各自帶有「任務」區段。**關聯至** 可將任務連結到家譜中的一或多筆記錄——人物、家庭、事件、姓名、來源、引文、媒體、地點、存放庫、地址或著作，但不能連結另一個任務、提交者或媒體連結；留空則為獨立任務。任務是共用的：在任何地方編輯都會更新同一筆記錄，刪除關聯記錄後任務仍會保留。若要重複使用共用任務而非新增任務，請使用**附加現有任務**。

著作、地址、關聯以及家庭的伴侶/子女連結擁有與主要實體分頁相同的筆記、來源和任務區段。聯絡方式屬於其所描述的人物、事件、儲存庫或提交者，而不屬於地址。任務保留筆記和媒體，但沒有來源、聯絡方式、貢獻者或任務區段。媒體連結不是附件的目標。 貢獻者僅在人物與家庭卡片上可用。

## 媒體

照片是專案旁邊 `media/` 資料夾中的一般檔案。可以從人物、家庭、來源、地點、儲存庫、提交者、作品、任務或地址中新增；媒體索引標籤的 **相關對象** 區段可把現有記錄附加到更多目標。每張媒體卡片只包含一個檔案。按一下預覽以開啟媒體索引標籤，在那裡可以編輯標題以及說明文字、順序、主要和排除等連結中繼資料。

一筆媒體記錄可以連結到多個目標。**從此記錄分離** 僅在媒體連結到多個目標時顯示，會移除一個連結。**刪除媒體** 會刪除記錄及其檔案副本。刪除目標記錄只會移除其連結，因此媒體記錄可以保留為無連結狀態。從包含多個檔案的 GEDCOM `OBJE` 匯入的媒體會變成每個檔案一張卡片；不會匯入替代格式 `TRAN`。

## 排序

順序重要的清單——姓名、家庭伴侶和子女、地點名稱、地址行、事件參與者和範本欄位——都有上移/下移控制項。順序以列位置儲存。
