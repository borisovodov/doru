# 疑難排解

- **舊版本建立的 `.doru` 專案無法開啟** — 1.0 之前，專案結構描述會在沒有移轉的情況下變更，因此無法理解其他版本寫入的檔案。請在建立該專案的版本中開啟它，匯出 GEDCOM，然後將該檔案匯入目前版本。
- **「AI 提供者未設定」** — 開啟設定（左側列中的齒輪圖示），選擇提供者，然後依照精靈操作：取得模型清單（或選擇模型），並在需要時儲存金鑰。
- **Ollama 連線失敗** — 選擇 Ollama 預設集（基礎 URL `http://localhost:11434/v1`）；無需 API 金鑰。按一下「從提供者取得模型」——如果回報無法連線到提供者，請確認 Ollama 正在本機執行。
