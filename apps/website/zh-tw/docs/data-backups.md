# 資料與備份

- 您的資料是一個普通檔案——而且始終屬於您。Dóru 沒有帳戶、沒有雲端後端、沒有遙測。除非*您*設定了遠端 AI 提供者，否則任何內容都不會上傳到任何地方——即使如此，聊天訊息以及助理透過其工具取得的家譜資料也會傳送給該提供者。如果您想把一切都留在自己的電腦上，本機提供者（Ollama、LM Studio）可以完全離線運作。
- 備份：停止所有可能寫入專案的處理程序——在 Dóru 中關閉專案，並停止 MCP 用戶端或其他工具——然後複製 `.doru` 檔案（如果有照片，還要複製它旁邊的 `media/` 資料夾）。就是這麼簡單。還原就是在專案關閉且沒有其他寫入處理程序執行時，把 `.doru` 檔案和 `media/` 資料夾都複製回來。當機後，在 Dóru 中開啟一次專案，讓 SQLite 回復可能殘留的日誌，然後在複製或還原前關閉它。
- 聊天工作階段儲存在應用程式資料目錄中，而不是 `.doru` 檔案內；如果需要，請另行備份。
- 該檔案適合版本控制：它是一個穩定的二進位檔——如果願意，可以提交到 git。

## 在機器之間同步

Dóru 沒有內建同步引擎——專案就是普通檔案，保持同步是您的事：iCloud Drive、Dropbox、rclone、rsync、USB 隨身碟，隨您喜歡。

一個注意事項：`.doru` 檔案是 SQLite 資料庫，用檔案同步工具即時同步**開啟中**的專案可能會複製到寫入一半的狀態並損壞檔案。安全的做法是：同步前關閉專案（或應用程式），並停止其他所有寫入處理程序。已正常關閉且沒有其他程式寫入的專案可以安全複製。當機後，在 Dóru 中開啟一次專案，讓 SQLite 回復可能殘留的日誌，然後在複製前關閉它。
