# 資料與備份

- 您的資料是一個普通檔案——而且始終屬於您。Dóru 沒有帳戶、沒有雲端後端、沒有遙測。除非*您*設定了 AI 提供者，否則任何內容都不會上傳到任何地方——即使如此，也只有您在聊天中傳送的內容會離開您的機器。如果您想把一切都留在自己的電腦上，本機提供者（Ollama、LM Studio）可以完全離線運作。
- 備份：複製 `.doru` 檔案（如果有照片，還要複製它旁邊的 `media/` 資料夾）。就是這麼簡單。還原就是把它複製回來。
- 該檔案適合版本控制：它是一個穩定的二進位檔——如果願意，可以提交到 git。

## 在機器之間同步

Dóru 沒有內建同步引擎——專案就是普通檔案，保持同步是您的事：iCloud Drive、Dropbox、rclone、rsync、USB 隨身碟，隨您喜歡。

一個注意事項：`.doru` 檔案是 SQLite 資料庫，用檔案同步工具即時同步**開啟中**的專案可能會複製到寫入一半的狀態並損壞檔案。安全的做法是：同步前關閉專案（或應用程式）。複製已關閉的專案總是安全的。
