# 快速開始

1. 啟動 Dóru，在起始頁按一下 **新增專案…**（或 **開啟專案或匯入 GEDCOM…**）。
2. **建立**會詢問位置和名稱，並在那裡建立一個 `.doru` 檔案；**開啟專案或匯入 GEDCOM** 會開啟現有的 `.doru` 檔案，或 `.ged`/`.gdz` GEDCOM 檔案——GEDCOM 檔案會以匯入的家譜啟動一個新的、尚未儲存的專案；之後請將其儲存為 `.doru`。檔案本身就是專案——它的名稱就是專案的名稱：

```
My Family.doru      家譜本身（SQLite，帶有應用程式 ID 標識）
media/              照片和掃描件，視需要建立（選用）
```

3. 匯入資料：新家譜會顯示一張空白卡片——按一下它，輸入姓名，用對勾確認，第一個人就會出現在畫布上；每張卡片都可以用同樣的方式新增子女、配偶和父母。GEDCOM 檔案透過 **開啟專案或匯入 GEDCOM**（第 2 步）匯入。要匯出，請開啟 **匯出** 分頁，選擇 **GEDCOM 7.0**（`.ged`）或 **GEDZIP**（`.gdz`，包含受管理的媒體檔案），然後確認儲存位置。

每個專案都在**自己的視窗**中開啟；人物、家譜編輯器和設定作為分頁在其中開啟。**新增視窗**（`⌘⇧N`，Linux 和 Windows 上為 `Ctrl+Shift+N`）會在不關閉目前專案的情況下開啟另一個起始頁，因此您可以匯入 GEDCOM 檔案或並排開啟第二棵家譜。最近使用的專案會列在起始頁上，開啟的專案視窗會在下次啟動時還原。按兩下 `*.doru` 檔案（或開啟 `doru://open?path=/…/family.doru` 連結）會在執行中的應用程式裡開啟它。

## 從連結開啟專案

應用程式註冊了 `doru://` URL 配置，因此 `doru://open?path=…` 連結可以開啟專案——對於 `.ged`/`.gdz` 則是匯入檔案——即使應用程式尚未執行：

- 路徑必須是**絕對路徑並經過 URL 編碼**（空格用 `%20` 等），例如 `doru://open?path=%2FUsers%2Fyou%2FFamily.doru`。
- 如果應用程式未執行，連結會啟動它並立即開啟專案。
- 如果應用程式已在執行，專案會在執行中的執行個體裡開啟——絕不會啟動第二個執行個體，而是聚焦現有視窗。
- 連結僅適用於應用程式直接開啟的檔案類型：`.doru` 專案和 `.ged`/`.gdz` GEDCOM 檔案。

在 macOS 上，`open "doru://open?path=…"` 可以從終端機或其他應用程式傳送連結；在 Linux 上，`xdg-open` 起相同作用。
