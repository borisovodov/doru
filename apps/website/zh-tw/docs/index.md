# 簡介

Dóru 是 AI 時代的家譜——一款家譜桌面應用程式。您的家譜存放在磁碟上的普通資料夾中，完全離線運作，並透過內建聊天或任何 MCP/ACP 用戶端由 AI 代理人驅動。

- **本地優先。** 除非您允許，否則任何內容都不會離開您的電腦。專案就是一個 `.doru` 檔案；照片存放在它旁邊的 `media/` 資料夾裡。沒有帳戶、沒有雲端、沒有遙測——您的資料始終屬於您。
- **開源。** 整個應用程式採用 MIT 授權——可自由用於任何用途、修改與再散布，完整原始碼公開可用。
- **AI 原生。** 內建助手 Dóru AI 完全在您的機器上執行。應用程式內聊天可以讀取和編輯家譜，外部工具（Claude Desktop、Cursor、程式設計代理人）可透過 MCP/ACP 操作它。
- **主題。** 九款內建主題，每款都有深色與淺色兩套配色，跟隨您的作業系統外觀。
