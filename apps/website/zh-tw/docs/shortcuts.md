# 鍵盤快速鍵

Dóru 遵循常見的編輯器慣例：macOS 上快速鍵使用 ⌘，Linux 和 Windows 上使用 Ctrl；Shift 和 Alt/Option（⌥）在所有平台上相同。快速鍵組合（帶 ⌘/Ctrl/Alt）可在任何位置使用，包括文字欄位和聊天輸入框；一般文字輸入永遠不會觸發快速鍵。

## 專案

| 動作 | macOS | Linux / Windows |
|---|---|---|
| 新增專案… | `⌘N` | `Ctrl+N` |
| 新增視窗 | `⌘⇧N` | `Ctrl+Shift+N` |
| 開啟專案或匯入 GEDCOM… | `⌘O` | `Ctrl+O` |
| 儲存 | `⌘S` | `Ctrl+S` |
| 匯出 GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| 開啟設定 | `⌘,` | `Ctrl+,` |

## 檢視

| 動作 | macOS | Linux / Windows |
|---|---|---|
| 開啟搜尋側邊欄 | `⌘⇧F` | `Ctrl+Shift+F` |

該快速鍵會開啟搜尋側邊欄，並將游標置於查詢欄位中，方便立即輸入。

## 分頁

| 動作 | macOS | Linux / Windows |
|---|---|---|
| 關閉分頁 | `⌘W` | `Ctrl+W` |
| 下一個分頁 | `⌘⇧]` | `Ctrl+Tab` |
| 上一個分頁 | `⌘⇧[` | `Ctrl+Shift+Tab` |
| 切換至分頁 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

分頁切換會在兩端循環。`⌘9`（`Ctrl+9`）一律跳至最後一個分頁，即使開啟的分頁少於九個。

## 編輯

| 動作 | macOS | Linux / Windows |
|---|---|---|
| 復原 | `⌘Z` | `Ctrl+Z` |
| 重做 | `⌘⇧Z` | `Ctrl+Shift+Z` |

畫布上的每個操作——包括新增人物及其家庭連結——都是一個可復原的步驟；AI 代理人所做的編輯也可以復原。

## 面板

| 動作 | macOS | Linux / Windows |
|---|---|---|
| 切換聊天面板 | `⌘⌥B` | `Ctrl+Alt+B` |

## 輸入時

在輸入框內，有幾個鍵的行為比較特殊：

- **聊天**：`Enter` 傳送訊息。
- **家譜搜尋**：`Esc` 清空搜尋框。
- **人物編輯器**：在筆記框中按 `Enter` 會新增您輸入的筆記。

## 標準選單快速鍵

檔案/編輯/檢視/視窗選單提供平台標準快速鍵：複製、剪下、貼上和全選；放大、縮小和重設縮放；全螢幕；重新載入和開發人員工具；最小化、關閉視窗和結束。這些遵循您的作業系統慣例，此處不再列出。

## 速查表

關閉所有分頁後，空的編輯器會輪流顯示五個快速鍵範例作為提醒；開啟並關閉分頁可看到另一組。

## 備註

透過 **開啟專案或匯入 GEDCOM…** 開啟 `.ged`/`.gdz` 檔案會將家譜匯入一個新的、尚未儲存的專案。匯出在 **匯出** 分頁中進行，提供 GEDCOM 7.0 和 GEDZIP（見[快速開始](getting-started.md)）。
