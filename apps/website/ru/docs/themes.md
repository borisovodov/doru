# Темы

Интерфейс оформляется полностью через пользовательские CSS-свойства,
применяемые на уровне приложения — никогда на уровне отдельного проекта.

- **Встроенная тема** — `doru`, один файл палитры JSON в каталоге `themes/`
  приложения: один файл на тему, без CSS. Файл содержит и `dark`, и `light`
  палитры; оформление операционной системы решает, какая применяется —
  переключите ОС в светлый режим, и Dóru мгновенно подхватит его. Имя файла —
  это id темы (`doru.json`); поле `name` внутри — отображаемое имя.
- Выберите тему в `settings.json` (см. [Настройки](settings.md)) одной строкой
  или на странице **Настройки** в приложении (раскрывающийся список «Тема»);
  выбор в любом случае сохраняется в `settings.json`.
- Цвета (`colors`) активной палитры при запуске преобразуются в пользовательские
  CSS-свойства `--doru-*`.

## Пользовательские темы

Положите файл `<id>.json` с палитрами `dark` и `light` в каталог `themes`
внутри каталога данных приложения (туда же, где лежит `settings.json` — см.
[Настройки](settings.md)), затем выберите его с помощью `"theme": "<id>"` в
`settings.json`. После добавления файла перезапустите приложение, чтобы он
подхватился. Каталог создаётся при первом запуске; пользовательская тема, чей
id совпадает со встроенной, переопределяет её. Файл темы, который повреждён или
не соответствует схеме, пропускается (в лог пишется предупреждение), как и
отсутствующий, и не появляется в списке тем. Встроенные темы содержат ссылку
`$schema` (`https://doru.family/theme.json`) — добавьте ту же строку в свой
файл, чтобы получить автодополнение и проверку в редакторах, понимающих JSON
Schema.

Встроенные темы, у каждой тёмная и светлая палитры:

| Id темы | Отображаемое имя |
|---|---|
| `doru` (по умолчанию) | Dóru |
| `one-dark` | One Dark |
| `github` | GitHub |
| `solarized` | Solarized |
| `gruvbox` | Gruvbox |
| `catppuccin` | Catppuccin |
| `ayu` | Ayu |
| `rose-pine` | Rosé Pine |
| `everforest` | Everforest |

Палитра Dóru по умолчанию следует за значком приложения: глубокий лесной
зелёный с тёплыми бумажными тонами. Тёмная палитра наслаивает поверхности от
почти чёрного холста с зелёным оттенком к более светлому хрому и всплывающим
окнам; светлая палитра использует тёплую бумагу и кремовый.

Доступные переменные:

| Переменная | Значение |
|---|---|
| `--doru-bg-canvas` | фон редактора и полоса вкладок |
| `--doru-bg-chrome` | панель активности, боковые панели, поверхность плавающей панели |
| `--doru-bg-raised` | карточки, чипы, поле ввода чата |
| `--doru-bg-popover` | меню и средства выбора |
| `--doru-bg-input` | кнопки, поля ввода, раскрывающиеся списки |
| `--doru-fg` / `--doru-fg-muted` / `--doru-fg-faint` | основной, приглушённый и слабый текст |
| `--doru-border` / `--doru-border-strong` | тонкие линии и более сильные границы |
| `--doru-accent` / `--doru-accent-hover` / `--doru-accent-active` | акцент (лесной/шалфейный зелёный) |
| `--doru-on-accent` | текст на акцентном фоне |
| `--doru-accent-alpha` | полупрозрачный акцент (чипы, пузыри чата) |
| `--doru-focus` | цвет кольца фокуса |
| `--doru-overlay-hover` / `--doru-overlay-pressed` | наложения при наведении/нажатии |
| `--doru-success` / `--doru-warning` / `--doru-danger` / `--doru-info` | цвета состояний |
| `--doru-radius-sm` / `--doru-radius-md` / `--doru-radius-lg` | радиусы 4 / 6 / 8 px |
| `--doru-control-height` | высота элемента управления (28px) |
| `--doru-panel-gutter` | зазор между плавающими панелями и краем окна (4px) |
| `--doru-panel-radius` | радиус углов плавающей панели (8px) |
