# Клавиатурные сокращения

Dóru следует обычным соглашениям редакторов: в macOS в сокращениях используется
⌘, в Linux и Windows — Ctrl; Shift и Alt/Option (⌥) одинаковы везде. Комбинации
с ⌘/Ctrl/Alt работают где угодно, включая текстовые поля и поле ввода чата;
обычный ввод никогда не запускает сокращение.

## Проекты

| Действие | macOS | Linux / Windows |
|---|---|---|
| Новый проект… | `⌘N` | `Ctrl+N` |
| Новое окно | `⌘⇧N` | `Ctrl+Shift+N` |
| Открыть проект или импортировать GEDCOM… | `⌘O` | `Ctrl+O` |
| Сохранить | `⌘S` | `Ctrl+S` |
| Экспорт GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Открыть настройки | `⌘,` | `Ctrl+,` |

## Представления

| Действие | macOS | Linux / Windows |
|---|---|---|
| Открыть боковую панель поиска | `⌘⇧F` | `Ctrl+Shift+F` |

Сокращение открывает боковую панель поиска и ставит курсор в поле запроса,
готовое к вводу.

## Вкладки

| Действие | macOS | Linux / Windows |
|---|---|---|
| Закрыть вкладку | `⌘W` | `Ctrl+W` |
| Следующая вкладка | `⌘⇧]` | `Ctrl+Tab` |
| Предыдущая вкладка | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Перейти на вкладку 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Переключение вкладок зациклено. `⌘9` (`Ctrl+9`) всегда переходит к последней
вкладке, даже если открыто меньше девяти.

## Редактирование

| Действие | macOS | Linux / Windows |
|---|---|---|
| Отменить | `⌘Z` | `Ctrl+Z` |
| Повторить | `⌘⇧Z` | `Ctrl+Shift+Z` |

Каждое действие на холсте — включая добавление персоны вместе со связью с
семьёй — это один шаг отмены; изменения, сделанные ИИ-агентами, тоже можно
отменить.

## Панели

| Действие | macOS | Linux / Windows |
|---|---|---|
| Показать/скрыть панель чата | `⌘⌥B` | `Ctrl+Alt+B` |

## При вводе текста

Некоторые клавиши внутри полей ввода ведут себя особым образом:

- **Чат**: `Enter` отправляет сообщение.
- **Поиск по древу**: `Esc` очищает поле поиска.
- **Редактор персоны**: `Enter` в поле заметок добавляет введённую заметку.

## Стандартные сокращения меню

В меню «Файл/Правка/Вид/Окно» используются стандартные для платформы сочетания:
копировать, вырезать, вставить и выделить всё; увеличить, уменьшить и сбросить
масштаб; полноэкранный режим; перезагрузить и инструменты разработчика;
свернуть, закрыть окно и выйти. Они следуют соглашениям вашей операционной
системы и здесь не перечислены.

## Шпаргалка

Когда все вкладки закрыты, пустой редактор показывает вращающуюся подборку из
пяти сокращений в качестве напоминания; откройте и закройте вкладку,
чтобы увидеть другой набор.

## Примечания

Открытие файла `.ged`/`.gdz` через **Открыть проект или импортировать
GEDCOM…** импортирует древо в новый, ещё не сохранённый проект. Экспорт
выполняется на вкладке **Экспорт**, которая предлагает GEDCOM 7.0 и GEDZIP
(см. [быстрый старт](getting-started.md)).
