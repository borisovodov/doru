# Данные и резервные копии

- Ваши данные — это обычный файл, и он остаётся вашим. В Dóru нет аккаунтов,
  облачного бэкенда и телеметрии. Ничего никуда не загружается, если только *вы*
  не настроите удалённого ИИ-провайдера — и даже тогда сообщения чата и данные
  древа, которые ассистент получает через свои инструменты, отправляются этому
  провайдеру. Если хотите держать всё на компьютере, локальные провайдеры
  (Ollama, LM Studio) работают полностью офлайн.
- Для резервной копии остановите все процессы, которые могут записывать в проект
  — закройте его в Dóru и остановите клиенты MCP или другие инструменты — затем
  скопируйте файл `.doru` (и папку `media/` рядом с ним, если у вас есть
  фотографии). Это всё. Восстановление — копирование обратно.
- Сессии чата хранятся в каталоге данных приложения, а не внутри файла `.doru`;
  при необходимости создавайте для них отдельную резервную копию.
- Файл хорошо подходит для контроля версий: это стабильный бинарный файл — при
  желании коммитьте его в git.

## Синхронизация между машинами

В Dóru нет встроенной системы синхронизации — проекты — это обычные файлы, и
поддерживать их синхронизацию — ваша задача: iCloud Drive, Dropbox, rclone,
rsync, USB-флешка — что предпочитаете.

Одно предостережение: файл `.doru` — это база данных SQLite, и синхронизация
**открытого** проекта в реальном времени с помощью инструмента синхронизации
файлов может скопировать файл в полузаписанном состоянии и повредить его.
Безопасная практика: закройте проект (или приложение) и остановите все другие
процессы записи перед синхронизацией. Копирование закрытого проекта, в который
никто больше не пишет, всегда безопасно.
