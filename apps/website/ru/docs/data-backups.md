# Данные и резервные копии

- Ваши данные — это обычный файл, и он остаётся вашим. В Dóru нет аккаунтов,
  облачного бэкенда и телеметрии. Ничего никуда не загружается, если только
  *вы* не настроите ИИ-провайдера — и даже тогда с вашей машины уходит только
  то содержимое, которое вы отправляете в чате. Если хотите держать всё на
  компьютере, локальные провайдеры (Ollama, LM Studio) работают полностью
  офлайн.
- Для резервной копии скопируйте файл `.doru` (и папку `media/` рядом с ним,
  если у вас есть фотографии). Это всё. Восстановление — копирование обратно.
- Файл хорошо подходит для контроля версий: это стабильный бинарный файл — при
  желании коммитьте его в git.

## Синхронизация между машинами

В Dóru нет встроенной системы синхронизации — проекты — это обычные файлы, и
поддерживать их синхронизацию — ваша задача: iCloud Drive, Dropbox, rclone,
rsync, USB-флешка — что предпочитаете.

Одно предостережение: файл `.doru` — это база данных SQLite, и синхронизация
**открытого** проекта в реальном времени с помощью инструмента синхронизации
файлов может скопировать файл в полузаписанном состоянии и повредить его.
Безопасная практика: закрывайте проект (или приложение) перед синхронизацией.
Копирование закрытого проекта всегда безопасно.
