# ИИ и агенты

## Чат в приложении

Панель чата находится внизу окна. Введите вопрос, и агент сможет читать и
редактировать древо с помощью встроенных инструментов: `tree_query`, `tree_get`,
`tree_stats`, `tree_edit`, `tree_add_relative`, `sources_add`, `notes_write`.

Разговоры сохраняются как **сессии чата**: в заголовке панели чата перечислены
ваши сессии, между ними можно переключаться, начинать новый чат или удалять их.
Сессии хранятся для каждого проекта в каталоге данных приложения (не внутри
файла `.doru`), название берётся из вашего первого сообщения, и всё переживает
перезапуски приложения. У каждого ответа есть кнопка копирования, которая
помещает его исходный markdown в системный буфер обмена.

Провайдер настраивается в разделе `ai` файла `settings.json` (см.
[Настройки](settings.md)):

- **Пресеты провайдеров**: Ollama, LM Studio, пользовательская конечная точка,
  совместимая с OpenAI, или ACP-агент. Облачные пресеты возвращаются по одному
  по мере пересборки их интеграций. Задайте id в `"provider"`; каждый пресет
  предоставляет базовый URL по умолчанию, а модель выбирается в мастере
  настроек — загружается у провайдера для локальных конечных точек, выбирается
  из поставляемого каталога для облачных пресетов. Каждый провайдер хранит свою
  конфигурацию (модель, базовый URL, рассуждения, ключ) в `"providers"` — при
  переключении провайдеров восстанавливаются сохранённые настройки каждого.
- **Ключи API** хранятся в `secrets.json` (права 0600) в каталоге данных
  приложения с ключом по id провайдера. Ключ никогда не попадает в файл
  настроек.

## Dóru AI (офлайн-ассистент)

Провайдер по умолчанию — **Dóru AI**: локальный ассистент, работающий целиком
на вашем компьютере. Скачайте его один раз в настройках ИИ (один файл, около
3 ГБ); после этого чат работает без аккаунта и подключения к интернету. Он
выбран по умолчанию при чистой установке и требует не менее 8 ГБ оперативной
памяти.

Скачанная модель — Qwen3.5-4B (GGUF, квантование Q4_K_M, лицензия Apache-2.0 —
см. [карточку модели](https://huggingface.co/Qwen/Qwen3.5-4B)). Веса закреплены
по SHA-256 в манифесте приложения и проверяются после каждой загрузки.

## ACP-агенты

Задайте `"ai": { "provider": "acp", "providers": { "acp": { "command": "…",
"args": [] } } }`, чтобы общаться с агентом, поддерживающим Agent Client
Protocol (агенты в стиле Zed). Dóru передаёт проект агенту как MCP-сервер,
поэтому агент может запрашивать и редактировать древо так же, как встроенный
чат.

## Dóru как MCP-сервер

Любой MCP-клиент — Claude Desktop, Cursor, агенты для программирования — может
работать с вашим древом. Запустите Dóru в режиме сервера, указав файл `.doru`:

```sh
doru --mcp-server /absolute/path/to/family.doru
```

Пример конфигурации Claude Desktop
(`Claude → Settings → Developer → Edit Config`):

```json
{
  "mcpServers": {
    "doru": {
      "command": "/Applications/Doru.app/Contents/MacOS/doru",
      "args": ["--mcp-server", "/Users/you/FamilyHistory/family.doru"]
    }
  }
}
```

Linux AppImage: путь к файлу AppImage. Windows:
`"command": "C:\\Program Files\\Doru\\doru.exe"`. Имена инструментов остаются на
английском независимо от языка интерфейса.

Сервер **без графического интерфейса и без сохранения состояния**: без окна, без значка в доке,
без сессий чата — он читает и редактирует файл древа напрямую и завершается,
когда клиент отключается. Любое число клиентов может одновременно указывать на
один и тот же файл (Claude Desktop, Cursor, несколько агентов для
программирования); параллельные записи безопасно встают в очередь. Если клиент
не может запустить сервер, выполните команду в терминале — помощник записывает
проблемы в stderr, а его временный профиль удаляется при выходе.

## Примеры запросов

- *«Найдите всех, кто родился до 1850 года, и перечислите их источники».*
- *«Добавьте Ивана Иванова, родившегося около 1923 года, ребёнком Петра и
  Марии».*
- *«Напишите исследовательскую заметку об Анне в связи с переписью 1901
  года».*
- *«Проверьте моё древо на людей, родившихся после смерти родителей».*
