# Решение проблем

- **Проект `.doru` из старой сборки отказывается открываться** — до 1.0 схема
  проекта меняется без миграций, поэтому файлы, записанные другой сборкой, не
  понимаются. Откройте проект в сборке, которая его создала, экспортируйте
  GEDCOM и импортируйте этот файл в текущую сборку.
- **«ИИ-провайдер не настроен»** — откройте «Настройки» (значок шестерёнки на
  левой панели), выберите провайдера и следуйте мастеру: загрузите список
  моделей (или выберите модель) и сохраните ключ, где он требуется.
- **Не удаётся подключиться к Ollama** — выберите пресет Ollama (базовый URL
  `http://localhost:11434/v1`); ключ API не нужен. Нажмите «Загрузить модели у
  провайдера» — если сообщается, что провайдер недоступен, убедитесь, что
  Ollama запущен локально.
