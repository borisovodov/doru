# Введение

Dóru — генеалогия в эру ИИ, настольное приложение для вашего семейного древа.
Ваше древо живёт в обычной папке на диске, работает полностью офлайн, а
управляют им ИИ-агенты — через встроенный чат или любой MCP/ACP-клиент.

- **Локальность прежде всего.** Проект — это один файл `.doru`; фотографии
  лежат в папке `media/` рядом с ним. Ни аккаунтов, ни облака, ни телеметрии.
  Ваши данные остаются на компьютере, если только вы не настроите удалённого
  провайдера ИИ — тогда сообщения чата и записи древа, которые ассистент
  получает через свои инструменты, отправляются этому провайдеру. Локальные
  провайдеры работают полностью офлайн.
- **Открытый исходный код.** Всё приложение под лицензией MIT — свободно для
  любого использования, изменения и распространения, полный исходный код
  доступен.
- **ИИ в основе.** Встроенный ассистент Dóru AI работает целиком на вашей
  машине. Чат в приложении читает и редактирует древо, а внешние инструменты
  (Claude Desktop, Cursor, агенты для программирования) работают с ним через
  MCP/ACP.
- **Темы.** Девять встроенных тем, у каждой — тёмная и светлая палитры,
  которые следуют за оформлением ОС.
