# Быстрый старт

1. Запустите Dóru и нажмите **Создать новый проект…** (или **Открыть проект
   или импортировать GEDCOM…**) на стартовой странице.
2. **Создать** запрашивает расположение и имя и создаёт там файл `.doru`;
   **Открыть проект или импортировать GEDCOM** открывает существующий файл
   `.doru` или файл GEDCOM `.ged`/`.gdz` — файл GEDCOM запускает новый, ещё не
   сохранённый проект с импортированным древом; после этого сохраните его в
   `.doru`. Файл *и есть* проект — его имя является именем проекта:

   ```
   My Family.doru      само древо (SQLite, с идентификатором приложения)
   media/              фотографии и сканы, создаётся по необходимости (необязательно)
   ```

3. Добавьте данные: новое древо показывает одну пустую карточку — нажмите на
   неё, введите имя, подтвердите галочкой, и первая персона появится на
   холсте; каждая карточка может добавлять детей, супругов и родителей таким
   же образом. Файлы GEDCOM импортируются через **Открыть проект или импортировать
   GEDCOM** (шаг 2). Для экспорта откройте вкладку **Экспорт**, выберите
   **GEDCOM 7.0** (`.ged`) или **GEDZIP** (`.gdz`, с включёнными медиафайлами)
   и подтвердите место сохранения.

Каждый проект открывается в **отдельном окне**; персоны, редактор древа и
настройки открываются во вкладках внутри него. **Новое окно** (`⌘⇧N`, в Linux
и Windows — `Ctrl+Shift+N`) открывает ещё одну стартовую страницу, не закрывая
текущий проект, так что можно импортировать файл GEDCOM или открыть второе
древо рядом. Недавние проекты перечислены на стартовой странице, а окна
открытых проектов восстанавливаются при следующем запуске.
Двойной щелчок по файлу `*.doru` (или открытие ссылки
`doru://open?path=/…/family.doru`) открывает его в запущенном приложении.

## Открытие проектов по ссылкам

Приложение регистрирует схему URL `doru://`, поэтому ссылка
`doru://open?path=…` открывает проект — или импортирует файл, для
`.ged`/`.gdz` — даже если приложение ещё не запущено:

- Путь должен быть **абсолютным и закодированным в URL** (`%20` для пробелов
  и т. д.), например `doru://open?path=%2FUsers%2Fyou%2FFamily.doru`.
- Если приложение не запущено, ссылка запускает его и сразу открывает проект.
- Если приложение уже запущено, проект открывается в работающем экземпляре
  — второй экземпляр никогда не запускается, существующее окно получает
  фокус.
- Ссылки работают только для типов файлов, которые приложение открывает
  напрямую: проектов `.doru` и файлов GEDCOM `.ged`/`.gdz`.

В macOS команда `open "doru://open?path=…"` отправляет ссылку из терминала или
других приложений; в Linux то же самое делает `xdg-open`.
