# Raccourcis clavier

Dóru suit les conventions habituelles des éditeurs : sous macOS, les raccourcis
utilisent ⌘, sous Linux et Windows Ctrl ; Maj et Alt/Option (⌥) sont identiques
partout. Les combinaisons (avec ⌘/Ctrl/Alt) fonctionnent partout, y compris dans
les champs de texte et la saisie du chat ; la frappe simple ne déclenche jamais un
raccourci.

## Projets

| Action | macOS | Linux / Windows |
|---|---|---|
| Nouveau projet… | `⌘N` | `Ctrl+N` |
| Nouvelle fenêtre | `⌘⇧N` | `Ctrl+Shift+N` |
| Ouvrir un projet ou importer un GEDCOM… | `⌘O` | `Ctrl+O` |
| Enregistrer | `⌘S` | `Ctrl+S` |
| Exporter en GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Ouvrir les paramètres | `⌘,` | `Ctrl+,` |

## Vues

| Action | macOS | Linux / Windows |
|---|---|---|
| Ouvrir la barre latérale de recherche | `⌘⇧F` | `Ctrl+Shift+F` |

Le raccourci ouvre la barre latérale de recherche et place le curseur dans le
champ de requête, prêt à saisir.

## Onglets

| Action | macOS | Linux / Windows |
|---|---|---|
| Fermer l'onglet | `⌘W` | `Ctrl+W` |
| Onglet suivant | `⌘⇧]` | `Ctrl+Tab` |
| Onglet précédent | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Aller à l'onglet 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Le changement d'onglet boucle aux extrémités. `⌘9` (`Ctrl+9`) saute toujours au
dernier onglet, même lorsque moins de neuf sont ouverts.

## Édition

| Action | macOS | Linux / Windows |
|---|---|---|
| Annuler | `⌘Z` | `Ctrl+Z` |
| Rétablir | `⌘⇧Z` | `Ctrl+Shift+Z` |

Chaque action sur le canevas — y compris l'ajout d'une personne avec son lien
familial — est une étape annulable ; les modifications faites par les agents IA
peuvent aussi être annulées.

## Panneaux

| Action | macOS | Linux / Windows |
|---|---|---|
| Afficher/masquer le panneau de chat | `⌘⌥B` | `Ctrl+Alt+B` |

## Pendant la saisie

Quelques touches se comportent différemment dans les champs de saisie :

- **Chat** : `Enter` envoie le message.
- **Recherche dans l'arbre** : `Esc` vide le champ de recherche.
- **Éditeur de personne** : `Enter` dans la zone de notes ajoute la note saisie.

## Raccourcis de menu standard

Les menus Fichier/Édition/Affichage/Fenêtre utilisent les accélérateurs standard de
la plateforme : copier, couper, coller et tout sélectionner ; zoom avant, zoom
arrière et réinitialiser le zoom ; plein écran ; recharger et outils de
développement ; réduire, fermer la fenêtre et quitter. Ils suivent les conventions
de votre système d'exploitation et ne sont pas listés ici.

## Aide-mémoire

Lorsque tous les onglets sont fermés, l'éditeur vide affiche un échantillon rotatif
de cinq raccourcis en guise de rappel ; fermez et rouvrez un onglet pour en voir un
autre ensemble.

## Remarques

Ouvrir un fichier `.ged`/`.gdz` via **Ouvrir un projet ou importer un GEDCOM…**
importe l'arbre dans un nouveau projet pas encore enregistré. L'export se fait dans
l'onglet **Exporter**, qui propose GEDCOM 7.0 et GEDZIP (voir
[Démarrage rapide](getting-started.md)).
