# Klávesové zkratky

Dóru se řídí obvyklými konvencemi editorů: na macOS zkratky používají ⌘, na
Linuxu a Windows Ctrl; Shift a Alt/Option (⌥) jsou všude stejné. Kombinace
zkratek (s ⌘/Ctrl/Alt) fungují odkudkoli, včetně textových polí a vstupu chatu;
prosté psaní nikdy zkratku nespustí.

## Projekty

| Akce | macOS | Linux / Windows |
|---|---|---|
| Nový projekt… | `⌘N` | `Ctrl+N` |
| Nové okno | `⌘⇧N` | `Ctrl+Shift+N` |
| Otevřít projekt nebo importovat GEDCOM… | `⌘O` | `Ctrl+O` |
| Uložit | `⌘S` | `Ctrl+S` |
| Exportovat GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Otevřít nastavení | `⌘,` | `Ctrl+,` |

## Pohledy

| Akce | macOS | Linux / Windows |
|---|---|---|
| Otevřít postranní panel Hledat | `⌘⇧F` | `Ctrl+Shift+F` |

Zkratka otevře postranní panel Hledat a umístí kurzor do pole dotazu, připravený
k psaní.

## Karty

| Akce | macOS | Linux / Windows |
|---|---|---|
| Zavřít kartu | `⌘W` | `Ctrl+W` |
| Další karta | `⌘⇧]` | `Ctrl+Tab` |
| Předchozí karta | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Přepnout na kartu 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Přepínání karet se na koncích zacyklí. `⌘9` (`Ctrl+9`) vždy skočí na poslední
kartu, i když je otevřeno méně než devět.

## Úpravy

| Akce | macOS | Linux / Windows |
|---|---|---|
| Zpět | `⌘Z` | `Ctrl+Z` |
| Znovu | `⌘⇧Z` | `Ctrl+Shift+Z` |

Každá akce na plátně — včetně přidání osoby spolu s její rodinnou vazbou — je
jeden krok, který lze vrátit; úpravy provedené agenty AI lze také vrátit.

## Panely

| Akce | macOS | Linux / Windows |
|---|---|---|
| Přepnout panel chatu | `⌘⌥B` | `Ctrl+Alt+B` |

## Během psaní

Několik kláves se ve vstupech chová zvláštním způsobem:

- **Chat**: `Enter` odešle zprávu.
- **Hledání ve stromu**: `Esc` vymaže pole hledání.
- **Editor osoby**: `Enter` v poli poznámek přidá napsanou poznámku.

## Standardní zkratky nabídek

Nabídky Soubor/Úpravy/Zobrazení/Okno obsahují standardní akcelerátory
platformy: kopírovat, vyjmout, vložit a vybrat vše; přiblížit, oddálit a
obnovit zvětšení; celá obrazovka; znovu načíst a vývojářské nástroje;
minimalizovat, zavřít okno a ukončit. Řídí se konvencemi vašeho operačního
systému a nejsou zde uvedeny.

## Tahák

Když jsou všechny karty zavřené, prázdný editor zobrazuje střídající se ukázku
pěti zkratek jako připomínku; otevřete a zavřete kartu, abyste viděli
jinou sadu.

## Poznámky

Otevření souboru `.ged`/`.gdz` přes **Otevřít projekt nebo importovat
GEDCOM…** importuje strom do nového, dosud neuloženého projektu. Export
probíhá na kartě **Exportovat GEDCOM**, která nabízí GEDCOM 7.0 a GEDZIP (viz
[Rychlý start](getting-started.md)).
