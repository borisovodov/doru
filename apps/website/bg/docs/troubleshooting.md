# Отстраняване на проблеми

- **Проект `.doru` от по-стара сборка отказва да се отвори** — преди 1.0 схемата на проекта се променя без миграции, така че файловете, записани от друга сборка, не се разбират. Отворете проекта в сборката, която го е създала, експортирайте GEDCOM и импортирайте този файл в текущата сборка.
- **„Доставчикът на ИИ не е конфигуриран“** — отворете Настройки (икона със зъбно колело в лявата лента), изберете доставчик и следвайте съветника: изтеглете списъка с модели (или изберете модел) и запазете ключ, където е необходимо.
- **Връзката с Ollama се проваля** — изберете шаблона Ollama (основен URL `http://localhost:11434/v1`); не е необходим API ключ. Натиснете „Изтегляне на модели от доставчика“ — ако съобщи, че доставчикът е недостъпен, уверете се, че Ollama работи локално.
