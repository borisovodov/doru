# Теми

Интерфейсът е стилизиран изцяло чрез CSS персонализирани свойства, приложени на ниво приложение — никога за отделен проект.

- **Вградена тема** — `doru`, един JSON файл с палитра в директорията `themes/` на приложението: един файл на тема, без CSS. Файлът съдържа както `dark`, така и `light` палитра; външният вид на операционната система решава коя се прилага — превключете ОС на светъл режим и Dóru следва веднага. Името на файла е идентификаторът на темата (`doru.json`); полето `name` вътре е показваното име.
- Изберете темата в `settings.json` (вижте [Настройки](settings.md)) с един низ или от страницата **Настройки** в приложението (падащо меню Тема); изборът се запазва в `settings.json` и в двата случая.
- `colors` на активната палитра се преобразуват в CSS персонализирани свойства `--doru-*` при стартиране.

## Потребителски теми

Поставете файл `<id>.json` с палитри `dark` и `light` в директорията `themes` в папката с данни на приложението (същото място, където живее `settings.json` — вижте [Настройки](settings.md)), след което го изберете с `"theme": "<id>"` в `settings.json`. Рестартирайте приложението след добавяне на файл, за да бъде възприет. Директорията се създава при първо стартиране; потребителска тема, чийто идентификатор съвпада с вградена, я замества. Файл с тема, който е повреден или не съответства на схемата, се пропуска (записва се предупреждение), както и липсващ, и не се появява в списъка с теми. Вградените теми носят референция `$schema` (`https://doru.family/theme.json`) — добавете същия ред към своя файл, за да получите автоматично довършване и валидиране в редактори, които разбират JSON Schema.

Вградени теми, всяка с тъмна и светла палитра:

| Идентификатор на тема | Показвано име |
|---|---|
| `doru` (по подразбиране) | Dóru |
| `one-dark` | One Dark |
| `github` | GitHub |
| `solarized` | Solarized |
| `gruvbox` | Gruvbox |
| `catppuccin` | Catppuccin |
| `ayu` | Ayu |
| `rose-pine` | Rosé Pine |
| `everforest` | Everforest |

Палитрата Dóru по подразбиране следва иконата на приложението: дълбоко горско зелено с топли хартиени тонове. Тъмната палитра наслоява повърхности от почти черно платно със зеленикав оттенък към по-светла рамка и изскачащи панели; светлата палитра използва топла хартия и крем.

Налични променливи:

| Променлива | Значение |
|---|---|
| `--doru-bg-canvas` | фон на редактора и лента на разделите |
| `--doru-bg-chrome` | лента с дейности, странични ленти, повърхност на плаващ панел |
| `--doru-bg-raised` | карти, чипове, полето за чат |
| `--doru-bg-popover` | менюта и избирачи |
| `--doru-bg-input` | бутони, полета за въвеждане, избирачи |
| `--doru-fg` / `--doru-fg-muted` / `--doru-fg-faint` | основен, приглушен и блед текст |
| `--doru-border` / `--doru-border-strong` | тънки линии и по-силни граници |
| `--doru-accent` / `--doru-accent-hover` / `--doru-accent-active` | акцент (горско/градински зелено) |
| `--doru-on-accent` | текст върху акцентния фон |
| `--doru-accent-alpha` | полупрозрачен акцент (чипове, балончета за чат) |
| `--doru-focus` | цвят на фокусиращия пръстен |
| `--doru-overlay-hover` / `--doru-overlay-pressed` | наслагвания при задържане/натискане |
| `--doru-success` / `--doru-warning` / `--doru-danger` / `--doru-info` | цветове на състоянието |
| `--doru-radius-sm` / `--doru-radius-md` / `--doru-radius-lg` | радиуси 4 / 6 / 8 px |
| `--doru-control-height` | височина на контрола (28px) |
| `--doru-panel-gutter` | разстояние между плаващите панели и ръба на прозореца (4px) |
| `--doru-panel-radius` | радиус на ъглите на плаващ панел (8px) |
