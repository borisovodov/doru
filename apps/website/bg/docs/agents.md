# ИИ и агенти

## Вграденият чат

Панелът за чат се намира в долната част на прозореца. Въведете въпрос и агентът може да чете и редактира дървото с вградени инструменти: `tree_query`, `tree_get`, `tree_stats`, `tree_edit`, `tree_add_relative`, `sources_add`, `notes_write`.

Разговорите се запазват като **чат сесии**: заглавната част на панела за чат изброява сесиите ви и можете да превключвате между тях, да започнете нов чат или да ги изтриете. Сесиите се съхраняват за всеки проект в папката с данни на приложението (не във файла `.doru`), заглавието идва от първото ви съобщение и всичко оцелява след рестартиране на приложението. Всеки отговор има бутон за копиране, който поставя суровия му markdown в системния клипборд.

Доставчикът се конфигурира в секцията `ai` на `settings.json` (вижте [Настройки](settings.md)):

- **Шаблони за доставчици**: Ollama, LM Studio, персонализирана крайна точка, съвместима с OpenAI, или ACP агент. Облачните шаблони се връщат един по един, докато интеграциите им се възстановяват. Задайте идентификатора в `"provider"`; всеки шаблон предоставя основен URL по подразбиране, а моделът се избира в съветника за настройки — извлечен от доставчика за локални крайни точки, избран от доставения каталог за облачни шаблони. Всеки доставчик пази собствената си конфигурация (модел, основен URL, разсъждение, ключ) под `"providers"` — превключването на доставчици възстановява запазената настройка на всеки.
- **API ключовете** се съхраняват в `secrets.json` (режим 0600) в папката с данни на приложението, ключовани по идентификатор на доставчика. Ключът никога не се появява във файла с настройки.

## Dóru AI (офлайн асистент)

Доставчикът по подразбиране е **Dóru AI**: локален асистент, който работи изцяло на вашия компютър. Изтеглете го веднъж в настройките за ИИ (един файл, около 3 GB); след това чатът работи без акаунт и без интернет връзка. Избран е по подразбиране при нова инсталация и се нуждае от поне 8 GB RAM.

Изтегленият модел е Qwen3.5-4B (квантизиран GGUF Q4_K_M, лиценз Apache-2.0 — вижте [картата на модела](https://huggingface.co/Qwen/Qwen3.5-4B)). Теглата са фиксирани с SHA-256 в манифеста на приложението и се проверяват след всяко изтегляне.

## ACP агенти

Задайте `"ai": { "provider": "acp", "providers": { "acp": { "command": "…", "args": [] } } }`, за да говорите с агент, който говори Agent Client Protocol (агенти в стил Zed). Dóru предава проекта на агента като MCP сървър, така че агентът може да прави заявки и да редактира дървото точно като вградения чат.

## Dóru като MCP сървър

Всеки MCP клиент — Claude Desktop, Cursor, агенти за програмиране — може да работи с вашето дърво. Стартирайте Dóru в режим на сървър, сочейки към файла `.doru`:

```sh
doru --mcp-server /absolute/path/to/family.doru
```

Пример за конфигурация на Claude Desktop (`Claude → Settings → Developer → Edit Config`):

```json
{
  "mcpServers": {
    "doru": {
      "command": "/Applications/Doru.app/Contents/MacOS/doru",
      "args": ["--mcp-server", "/Users/you/FamilyHistory/family.doru"]
    }
  }
}
```

Linux AppImage: пътят до файла на AppImage. Windows: `"command": "C:\\Program Files\\Doru\\doru.exe"`. Имената на инструментите остават на английски независимо от езика на интерфейса.

Сървърът е **без графичен интерфейс и без състояние**: без прозорец, без икона в дока, без чат сесии — той чете и редактира файла на дървото директно и излиза, когато клиентът се разкачи. Произволен брой клиенти могат да сочат към същия файл едновременно (Claude Desktop, Cursor, няколко агента за програмиране); едновременните записи се подреждат безопасно. Ако клиент не може да стартира сървъра, изпълнете командата в терминал — помощната програма записва проблемите в stderr и временният ѝ профил се изхвърля при изход.
