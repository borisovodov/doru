# 使用家谱

家谱以交互式画布形式打开。以下操作都在画布上完成；人物列表位于左侧活动栏的 **人物** 视图中。

## 导航

- 拖动背景进行**平移**，使用滚轮或触控板**缩放**；缩放按钮位于画布角落。
- 双击人物卡片可**重新聚焦**到该人物。工具栏会保留历史记录：后退/前进箭头和面包屑路径。
- **图表**：在工具栏中切换 *祖先*、*后代*、*沙漏* 和 *家庭* 视图。家庭视图显示焦点夫妇、他们的子女以及双方的父母。
- **搜索**：在工具栏搜索框中输入姓名，选择结果即可跳转到该人物。
- **折叠**卡片上的箭头可折叠分支（也可从工具栏折叠/展开所有分支）。

## 卡片

每张卡片显示姓名首字母头像、姓名、生卒年份（已故人物带 †），以及统计笔记、来源和媒体数量的小徽章。左边缘在祖先图中标示父系（蓝色）和母系（粉色），强调边框标示焦点人物。

## 编辑

选择卡片会显示操作工具栏：

- **添加子女 / 配偶 / 父母** — 人物旁边会出现一张新的空白卡片；直接在卡片中输入姓名并用对勾确认（叉号则丢弃）。
- **编辑** — 以标签页形式打开完整的人物编辑器：姓名、性别、出生/死亡日期及质量标记（*精确 / 大约 / 之前 / 之后*）和自由文本形式（例如无法映射到公历的历法日期“23 Nivôse”）、家庭、事件、来源、笔记和媒体。
- **删除** — 将人物从家谱和所有家庭中移除。
- **更改父母**：将卡片拖到另一个人物的卡片上，可将拖动的人物作为子女移入该家庭（拖动时有效目标会高亮显示）。

新建（空白）家谱会显示一张空白卡片：点击它，输入姓名，用对勾确认，第一个人物就会出现在画布上。之后，从卡片本身逐步扩展家谱。

## 家庭

在完整的人物编辑器中，添加父母、伴侣或子女。输入姓名以选择现有的人物；标签会显示每个家庭的成员。从家庭中移除人物或删除家庭都只需点击一次。

## 来源与笔记

- **来源**：为人物附加来源（含标题和作者），或复用现有来源。每次附加都是一条引用，可以移除。
- **笔记**：附加到人物的自由形式研究笔记。一条笔记可以附加到多条记录：在另一条记录的“笔记”部分使用 **附加现有笔记**，然后选择编辑时是在所有地方更新共享文本，还是仅更新当前记录。**从此记录分离** 会移除一个链接；**在所有地方删除** 会删除该笔记。
- 事件和姓名在人物编辑器内各自拥有来源、笔记、标签、标识符、联系方式和限制部分。

## 地址

**来源** 视图有一个 **地址** 部分。用它来创建、编辑和删除独立地址。被事件、存储库或提交者使用的地址会显示使用次数；删除地址会将其从这些记录中分离。事件的地址选择器还提供 **新地址** 和 **编辑地址** 操作，可就地编辑地址。

## 任务

任务除了计划日期和提醒日期外，还有创建日期和结束日期。每个编辑器都有一个 **任务** 部分：在那里添加任务后，它会自动链接到该记录。事件、姓名、引文和笔记在其附加面板中各自带有“任务”部分。**关联到** 可将任务链接到家谱中的任何记录——人物、家庭、事件、姓名、来源、引文、笔记、媒体文件、地点、存储库、提交者、地址、著作，甚至另一个任务；留空则为独立任务。

著作、任务、地址、关联以及家庭的伴侣/子女链接拥有与主要实体标签页相同的笔记、来源、标签、标识符、联系方式、限制、贡献者和任务部分。

## 媒体

照片是项目旁边 `media/` 文件夹中的普通文件。可从人物、家庭、来源、地点、存储库、提交者、著作、任务或地址添加。媒体部分还允许将现有记录附加到另一个目标。点击预览可打开媒体标签页，在其中编辑标题、管理文件，并编辑链接元数据，如说明文字、顺序、主要标志和排除标志。

一条媒体记录可以链接到多个目标。**从此记录分离** 会移除一个链接；**删除媒体** 会删除该记录及其文件副本。不再有任何链接的记录会被自动删除。

## 排序

顺序重要的列表——姓名、家庭伴侣和子女、地点名称、地址行、事件参与者和模板字段——都有上移/下移控件。顺序以行位置保存。
