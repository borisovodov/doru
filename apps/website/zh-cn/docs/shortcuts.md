# 键盘快捷键

Dóru 遵循常见的编辑器惯例：macOS 上快捷键使用 ⌘，Linux 和 Windows 上使用 Ctrl；Shift 和 Alt/Option（⌥）在所有平台上相同。快捷键组合（带 ⌘/Ctrl/Alt）可在任何位置使用，包括文本字段和聊天输入框；普通文字输入永远不会触发快捷键。

## 项目

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 新建项目… | `⌘N` | `Ctrl+N` |
| 新建窗口 | `⌘⇧N` | `Ctrl+Shift+N` |
| 打开项目或导入 GEDCOM… | `⌘O` | `Ctrl+O` |
| 保存 | `⌘S` | `Ctrl+S` |
| 导出 GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| 打开设置 | `⌘,` | `Ctrl+,` |

## 视图

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 打开搜索侧边栏 | `⌘⇧F` | `Ctrl+Shift+F` |

该快捷键会打开搜索侧边栏，并将光标置于查询字段中，方便立即输入。

## 标签页

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 关闭标签页 | `⌘W` | `Ctrl+W` |
| 下一个标签页 | `⌘⇧]` | `Ctrl+Tab` |
| 上一个标签页 | `⌘⇧[` | `Ctrl+Shift+Tab` |
| 切换到标签页 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

标签页切换在两端循环。`⌘9`（`Ctrl+9`）始终跳转到最后一个标签页，即使打开的标签页少于九个。

## 编辑

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 撤消 | `⌘Z` | `Ctrl+Z` |
| 重做 | `⌘⇧Z` | `Ctrl+Shift+Z` |

画布上的每个操作——包括添加人物及其家庭链接——都是一个可撤消的步骤；AI 智能体所做的编辑也可以撤消。

## 面板

| 操作 | macOS | Linux / Windows |
|---|---|---|
| 切换聊天面板 | `⌘⌥B` | `Ctrl+Alt+B` |

## 输入时

在输入框内，有几个键的行为比较特殊：

- **聊天**：`Enter` 发送消息。
- **家谱搜索**：`Esc` 清空搜索框。
- **人物编辑器**：在笔记框中按 `Enter` 会添加您输入的笔记。

## 标准菜单快捷键

文件/编辑/查看/窗口菜单提供平台标准加速键：复制、剪切、粘贴和全选；放大、缩小和重置缩放；全屏；重新加载和开发人员工具；最小化、关闭窗口和退出。这些遵循您的操作系统惯例，此处不再列出。

## 速查表

关闭所有标签页后，空的编辑器会轮流显示五个快捷键示例作为提醒；关闭并重新打开标签页可看到另一组。

## 说明

通过 **打开项目或导入 GEDCOM…** 打开 `.ged`/`.gdz` 文件会将家谱导入一个新的、尚未保存的项目。导出在 **导出** 标签页中进行，提供 GEDCOM 7.0 和 GEDZIP（见[快速开始](getting-started.md)）。
