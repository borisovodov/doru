# 故障排除

- **旧版本创建的 `.doru` 项目无法打开** — 1.0 之前，项目架构会在没有迁移的情况下变更，因此无法理解其他版本写入的文件。请在创建该项目的版本中打开它，导出 GEDCOM，然后将该文件导入当前版本。
- **“AI 提供商未配置”** — 打开设置（左侧栏中的齿轮图标），选择一个提供商，然后按照向导操作：获取模型列表（或选择模型），并在需要时保存密钥。
- **Ollama 连接失败** — 选择 Ollama 预设（基础 URL `http://localhost:11434/v1`）；无需 API 密钥。点击“从提供商获取模型”——如果报告无法访问提供商，请确保 Ollama 正在本地运行。
