# 数据与备份

- 您的数据是一个普通文件——而且始终属于您。Dóru 没有账户、没有云端后端、没有遥测。除非*您*配置了 AI 提供商，否则任何内容都不会上传到任何地方——即使如此，也只有您在聊天中发送的内容会离开您的机器。如果您想把一切都留在自己的电脑上，本地提供商（Ollama、LM Studio）可以完全离线工作。
- 备份：复制 `.doru` 文件（如果有照片，还要复制它旁边的 `media/` 文件夹）。就是这么简单。恢复就是把它复制回来。
- 该文件适合版本控制：它是一个稳定的二进制文件——如果愿意，可以提交到 git。

## 在机器之间同步

Dóru 没有内置同步引擎——项目就是普通文件，保持同步是您的事：iCloud Drive、Dropbox、rclone、rsync、U 盘，随您喜欢。

一个注意事项：`.doru` 文件是 SQLite 数据库，用文件同步工具实时同步**打开**的项目可能会复制到写入一半的状态并损坏文件。安全的做法是：同步前关闭项目（或应用）。复制已关闭的项目总是安全的。
