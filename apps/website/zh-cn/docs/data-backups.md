# 数据与备份

- 您的数据是一个普通文件——而且始终属于您。Dóru 没有账户、没有云端后端、没有遥测。除非*您*配置了远程 AI 提供商，否则任何内容都不会上传到任何地方——即使如此，聊天消息以及助手通过其工具获取的家谱数据也会发送给该提供商。如果您想把一切都留在自己的电脑上，本地提供商（Ollama、LM Studio）可以完全离线工作。
- 备份：停止所有可能写入项目的进程——在 Dóru 中关闭项目，并停止 MCP 客户端或其他工具——然后复制 `.doru` 文件（如果有照片，还要复制它旁边的 `media/` 文件夹）。就是这么简单。恢复就是在项目关闭且没有其他写入进程运行时，把它复制回来。
- 聊天会话保存在应用数据目录中，而不是 `.doru` 文件内；如果需要，请单独备份它们。
- 该文件适合版本控制：它是一个稳定的二进制文件——如果愿意，可以提交到 git。

## 在机器之间同步

Dóru 没有内置同步引擎——项目就是普通文件，保持同步是您的事：iCloud Drive、Dropbox、rclone、rsync、U 盘，随您喜欢。

一个注意事项：`.doru` 文件是 SQLite 数据库，用文件同步工具实时同步**打开**的项目可能会复制到写入一半的状态并损坏文件。安全的做法是：同步前关闭项目（或应用），并停止其他所有写入进程。复制已关闭且没有其他程序写入的项目总是安全的。崩溃后，在 Dóru 中打开一次项目，让 SQLite 回滚可能残留的日志，然后在复制前关闭它。
