# 快速开始

1. 启动 Dóru，在起始页点击 **新建项目…**（或 **打开项目或导入 GEDCOM…**）。
2. **创建**会询问位置和名称，并在那里创建一个 `.doru` 文件；**打开项目或导入 GEDCOM** 会打开现有的 `.doru` 文件，或 `.ged`/`.gdz` GEDCOM 文件——GEDCOM 文件会以导入的家谱启动一个新的、尚未保存的项目；之后请将其保存为 `.doru`。文件本身就是项目——它的名称就是项目的名称：

```
My Family.doru      家谱本身（SQLite，带有应用 ID 标识）
media/              照片和扫描件，按需创建（可选）
```

3. 导入数据：新家谱会显示一张空白卡片——点击它，输入姓名，用对勾确认，第一个人物就会出现在画布上；每张卡片都可以用同样的方式添加子女、配偶和父母。GEDCOM 文件通过 **打开项目或导入 GEDCOM**（第 2 步）导入。要导出，请打开 **导出** 标签页，选择 **GEDCOM 7.0**（`.ged`）或 **GEDZIP**（`.gdz`，包含管理的媒体文件），然后确认保存位置。

每个项目都在**自己的窗口**中打开；人物、家谱编辑器和设置作为标签页在其中打开。**新建窗口**（`⌘⇧N`，Linux 和 Windows 上为 `Ctrl+Shift+N`）会在不关闭当前项目的情况下打开另一个起始页，因此您可以导入 GEDCOM 文件或并排打开第二棵家谱。最近使用的项目会列在起始页上，打开的项目窗口会在下次启动时恢复。双击 `*.doru` 文件（或打开 `doru://open?path=/…/family.doru` 链接）会在正在运行的应用中打开它。

## 从链接打开项目

应用注册了 `doru://` URL 方案，因此 `doru://open?path=…` 链接可以打开项目——对于 `.ged`/`.gdz` 则是导入文件——即使应用尚未运行：

- 路径必须是**绝对路径并经过 URL 编码**（空格用 `%20` 等），例如 `doru://open?path=%2FUsers%2Fyou%2FFamily.doru`。
- 如果应用未运行，链接会启动它并立即打开项目。
- 如果应用已在运行，项目会在正在运行的实例中打开——绝不会启动第二个实例，而是聚焦现有窗口。
- 链接仅适用于应用直接打开的文件类型：`.doru` 项目和 `.ged`/`.gdz` GEDCOM 文件。

在 macOS 上，`open "doru://open?path=…"` 可以从终端或其他应用发送链接；在 Linux 上，`xdg-open` 起相同作用。
