# 简介

Dóru 是 AI 时代的家谱——一款用于家谱的桌面应用。您的家谱存放在磁盘上的普通文件夹中，完全离线运行，并通过内置聊天或任何 MCP/ACP 客户端由 AI 智能体驱动。

- **本地优先。** 除非您允许，否则任何内容都不会离开您的电脑。项目就是一个 `.doru` 文件；照片存放在它旁边的 `media/` 文件夹中。没有账户、没有云端、没有遥测——您的数据始终属于您。
- **开源。** 整个应用采用 MIT 许可证——可自由用于任何用途、修改和再分发，完整源代码公开可用。
- **AI 原生。** 内置助手 Dóru AI 完全在您的机器上运行。应用内聊天可以读取和编辑家谱，外部工具（Claude Desktop、Cursor、编程智能体）可通过 MCP/ACP 操作它。
- **主题。** 九款内置主题，每款都有深色和浅色两套配色，跟随您的操作系统外观。
