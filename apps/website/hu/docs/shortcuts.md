# Billentyűparancsok

A Dóru a szokásos szerkesztői konvenciókat követi: macOS-en a parancsokhoz ⌘, Linuxon és Windowson Ctrl; a Shift és az Alt/Option (⌥) mindenhol ugyanaz. A billentyűparancs-kombinációk (⌘/Ctrl/Alt használatával) bárhonnan működnek, beleértve a szövegmezőket és a csevegésbevitelt is; a sima gépelés soha nem indít el billentyűparancsot.

## Projektek

| Művelet | macOS | Linux / Windows |
|---|---|---|
| Új projekt… | `⌘N` | `Ctrl+N` |
| Új ablak | `⌘⇧N` | `Ctrl+Shift+N` |
| Projekt megnyitása vagy GEDCOM importálása… | `⌘O` | `Ctrl+O` |
| Mentés | `⌘S` | `Ctrl+S` |
| GEDCOM exportálása… | `⌘⇧E` | `Ctrl+Shift+E` |
| Beállítások megnyitása | `⌘,` | `Ctrl+,` |

## Nézetek

| Művelet | macOS | Linux / Windows |
|---|---|---|
| A Keresés oldalsáv megnyitása | `⌘⇧F` | `Ctrl+Shift+F` |

A parancs megnyitja a Keresés oldalsávot, és a kurzort a keresőmezőbe helyezi, gépelésre készen.

## Lapok

| Művelet | macOS | Linux / Windows |
|---|---|---|
| Lap bezárása | `⌘W` | `Ctrl+W` |
| Következő lap | `⌘⇧]` | `Ctrl+Tab` |
| Előző lap | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Váltás az 1–9. lapra | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

A lapváltás a végeken körbeér. A `⌘9` (`Ctrl+9`) mindig az utolsó lapra ugrik, még akkor is, ha kevesebb mint kilenc lap van nyitva.

## Szerkesztés

| Művelet | macOS | Linux / Windows |
|---|---|---|
| Visszavonás | `⌘Z` | `Ctrl+Z` |
| Újra | `⌘⇧Z` | `Ctrl+Shift+Z` |

Minden vászonművelet — beleértve egy személy és családi kapcsolata hozzáadását is — egyetlen visszavonható lépés; az MI-ügynökök által végzett szerkesztések is visszavonhatók.

## Panelek

| Művelet | macOS | Linux / Windows |
|---|---|---|
| A csevegőpanel be- és kikapcsolása | `⌘⌥B` | `Ctrl+Alt+B` |

## Gépelés közben

Néhány billentyű speciálisan viselkedik a beviteli mezőkben:

- **Csevegés**: az `Enter` elküldi az üzenetet.
- **Fa keresése**: az `Esc` törli a keresőmezőt.
- **Személyszerkesztő**: az `Enter` a jegyzetmezőben hozzáadja a beírt jegyzetet.

## Szabványos menüparancsok

A Fájl/Szerkesztés/Nézet/Ablak menük a platformszabványos gyorsítókat kínálják: másolás, kivágás, beillesztés és összes kijelölése; nagyítás, kicsinyítés és nagyítás visszaállítása; teljes képernyő; újratöltés és fejlesztői eszközök; minimalizálás, ablak bezárása és kilépés. Ezek az operációs rendszer konvencióit követik, és itt nincsenek felsorolva.

## Puska

Az összes lap bezárásakor az üres szerkesztő öt billentyűparancs forgó mintáját mutatja emlékeztetőként; zárjon be és nyisson meg egy lapot egy másik készlet megtekintéséhez.

## Megjegyzések

A `.ged`/`.gdz` fájl **Projekt megnyitása vagy GEDCOM importálása…** paranccsal történő megnyitása a fát egy új, még nem mentett projektbe importálja. Az exportálás az **Exportálás** lapon történik, amely GEDCOM 7.0-t és GEDZIP-et kínál (lásd [Gyors kezdés](getting-started.md)).
