# Tastenkürzel

Dóru folgt den üblichen Editor-Konventionen: Unter macOS verwenden Tastenkürzel
⌘, unter Linux und Windows Ctrl; Shift und Alt/Option (⌥) sind überall gleich.
Tastenkombinationen (mit ⌘/Ctrl/Alt) funktionieren überall, auch in Textfeldern
und der Chat-Eingabe; normales Tippen löst niemals ein Tastenkürzel aus.

## Projekte

| Aktion | macOS | Linux / Windows |
|---|---|---|
| Neues Projekt… | `⌘N` | `Ctrl+N` |
| Neues Fenster | `⌘⇧N` | `Ctrl+Shift+N` |
| Projekt öffnen oder GEDCOM importieren… | `⌘O` | `Ctrl+O` |
| Speichern | `⌘S` | `Ctrl+S` |
| GEDCOM exportieren… | `⌘⇧E` | `Ctrl+Shift+E` |
| Einstellungen öffnen | `⌘,` | `Ctrl+,` |

## Ansichten

| Aktion | macOS | Linux / Windows |
|---|---|---|
| Suchseitenleiste öffnen | `⌘⇧F` | `Ctrl+Shift+F` |

Das Kürzel öffnet die Suchseitenleiste und setzt den Cursor in das Abfragefeld,
bereit zum Tippen.

## Tabs

| Aktion | macOS | Linux / Windows |
|---|---|---|
| Tab schließen | `⌘W` | `Ctrl+W` |
| Nächster Tab | `⌘⇧]` | `Ctrl+Tab` |
| Vorheriger Tab | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Zu Tab 1–9 wechseln | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

Das Wechseln von Tabs läuft an den Enden um. `⌘9` (`Ctrl+9`) springt immer zum
letzten Tab, auch wenn weniger als neun geöffnet sind.

## Bearbeiten

| Aktion | macOS | Linux / Windows |
|---|---|---|
| Rückgängig | `⌘Z` | `Ctrl+Z` |
| Wiederholen | `⌘⇧Z` | `Ctrl+Shift+Z` |

Jede Aktion auf der Leinwand — einschließlich des Hinzufügens einer Person
zusammen mit ihrer Familienverknüpfung — ist ein rückgängig machbarer Schritt;
auch Änderungen von KI-Agenten lassen sich rückgängig machen.

## Panels

| Aktion | macOS | Linux / Windows |
|---|---|---|
| Chat-Panel ein-/ausblenden | `⌘⌥B` | `Ctrl+Alt+B` |

## Beim Tippen

Einige Tasten verhalten sich in Eingabefeldern besonders:

- **Chat**: `Enter` sendet die Nachricht.
- **Baumsuche**: `Esc` leert das Suchfeld.
- **Personen-Editor**: `Enter` im Notizfeld fügt die getippte Notiz hinzu.

## Standard-Menükürzel

Die Menüs Datei/Bearbeiten/Ansicht/Fenster verwenden die plattformüblichen
Tastenkombinationen: Kopieren, Ausschneiden, Einfügen und Alles auswählen;
Vergrößern, Verkleinern und Zoom zurücksetzen; Vollbild; Neu laden und
Entwicklerwerkzeuge; Minimieren, Fenster schließen und Beenden. Sie folgen den
Konventionen Ihres Betriebssystems und sind hier nicht aufgeführt.

## Spickzettel

Wenn alle Tabs geschlossen sind, zeigt der leere Editor eine rotierende Auswahl
von fünf Tastenkürzeln als Erinnerung; öffnen und schließen Sie einen Tab, um
einen anderen Satz zu sehen.

## Hinweise

Das Öffnen einer `.ged`/`.gdz`-Datei über **Projekt öffnen oder GEDCOM
importieren…** importiert den Stammbaum in ein neues, noch nicht gespeichertes
Projekt. Der Export erfolgt im Tab **Export**, der GEDCOM 7.0 und GEDZIP anbietet
(siehe [Schnellstart](getting-started.md)).
