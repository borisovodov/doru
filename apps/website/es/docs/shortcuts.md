# Atajos de teclado

Dóru sigue las convenciones habituales de los editores: en macOS los atajos usan
⌘, en Linux y Windows Ctrl; Mayús y Alt/Option (⌥) son iguales en todas partes. Las
combinaciones (con ⌘/Ctrl/Alt) funcionan desde cualquier sitio, incluidos los
campos de texto y la entrada del chat; escribir texto normal nunca activa un
atajo.

## Proyectos

| Acción | macOS | Linux / Windows |
|---|---|---|
| Nuevo proyecto… | `⌘N` | `Ctrl+N` |
| Nueva ventana | `⌘⇧N` | `Ctrl+Shift+N` |
| Abrir proyecto o importar GEDCOM… | `⌘O` | `Ctrl+O` |
| Guardar | `⌘S` | `Ctrl+S` |
| Exportar GEDCOM… | `⌘⇧E` | `Ctrl+Shift+E` |
| Abrir ajustes | `⌘,` | `Ctrl+,` |

## Vistas

| Acción | macOS | Linux / Windows |
|---|---|---|
| Abrir la barra lateral de búsqueda | `⌘⇧F` | `Ctrl+Shift+F` |

El atajo abre la barra lateral de búsqueda y coloca el cursor en el campo de
consulta, listo para escribir.

## Pestañas

| Acción | macOS | Linux / Windows |
|---|---|---|
| Cerrar pestaña | `⌘W` | `Ctrl+W` |
| Pestaña siguiente | `⌘⇧]` | `Ctrl+Tab` |
| Pestaña anterior | `⌘⇧[` | `Ctrl+Shift+Tab` |
| Ir a la pestaña 1–9 | `⌘1`…`⌘9` | `Ctrl+1`…`Ctrl+9` |

El cambio de pestaña da la vuelta en los extremos. `⌘9` (`Ctrl+9`) siempre salta a
la última pestaña, incluso cuando hay menos de nueve abiertas.

## Edición

| Acción | macOS | Linux / Windows |
|---|---|---|
| Deshacer | `⌘Z` | `Ctrl+Z` |
| Rehacer | `⌘⇧Z` | `Ctrl+Shift+Z` |

Cada acción del lienzo — incluida la de añadir una persona junto con su vínculo
familiar — es un paso que se puede deshacer; las ediciones hechas por agentes de
IA también se pueden deshacer.

## Paneles

| Acción | macOS | Linux / Windows |
|---|---|---|
| Mostrar/ocultar el panel de chat | `⌘⌥B` | `Ctrl+Alt+B` |

## Mientras escribes

Algunas teclas se comportan de forma especial dentro de los campos de entrada:

- **Chat**: `Enter` envía el mensaje.
- **Búsqueda en el árbol**: `Esc` borra el cuadro de búsqueda.
- **Editor de persona**: `Enter` en el cuadro de notas añade la nota que
  escribiste.

## Atajos de menú estándar

Los menús Archivo/Edición/Ver/Ventana incluyen los aceleradores estándar de la
plataforma: copiar, cortar, pegar y seleccionar todo; acercar, alejar y restablecer
el zoom; pantalla completa; recargar y herramientas de desarrollo; minimizar,
cerrar ventana y salir. Siguen las convenciones de tu sistema operativo y no se
enumeran aquí.

## Guía rápida

Con todas las pestañas cerradas, el editor vacío muestra una selección rotativa de
cinco atajos como recordatorio; abre y cierra una pestaña para ver otro
conjunto.

## Notas

Abrir un archivo `.ged`/`.gdz` mediante **Abrir proyecto o importar GEDCOM…**
importa el árbol a un proyecto nuevo aún no guardado. La exportación se hace en la
pestaña **Exportar**, que ofrece GEDCOM 7.0 y GEDZIP (ver
[inicio rápido](getting-started.md)).
