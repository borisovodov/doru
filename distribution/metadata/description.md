A desktop app for your family tree. Your tree lives in a plain folder on
your disk, works fully offline, and is driven by AI agents — through the
built-in chat or any MCP/ACP client.

- **Your tree, one canvas.** Four views — ancestors, descendants, hourglass,
  family — on one zoomable canvas. Add people in place, drag to reparent, and
  open full editors for dates, sources, and notes.
- **AI-native.** Agent chat with tree tools, a built-in assistant (Dóru AI)
  that runs entirely offline, any provider you like (Ollama, LM Studio, a
  cloud API, an ACP agent), an MCP server mode for Claude Desktop and Cursor,
  and an MCP host for external servers.
- **Private by design.** No accounts, no cloud, no telemetry. Nothing leaves
  your machine unless you say so.
- **Themes.** Nine built-in themes — from One Dark to Rosé Pine — each with
  dark and light palettes that follow your OS appearance.
- **GEDCOM.** Import GEDCOM 5.5 and 5.5.1, export GEDCOM 7.0 — .gdz archives
  included. Hundreds of vendor tags from real-world software are recognized,
  so nothing important is lost on the way in.
- **Portable & localized.** Back up by copying a folder; open it on macOS,
  Linux, or Windows. The interface is fully localized in 17 languages.

Dóru is free and open source (MIT).
