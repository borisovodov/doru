Dóru is local-first genealogy for the AI era. A project is a single `.doru`
file (SQLite) with photos in a media folder next to it — nothing is hidden,
nothing is uploaded.

- **Your tree, your disk.** Trees live in plain files on your machine and work
  fully offline. Back up by copying a folder; open it on macOS, Linux, or
  Windows.
- **AI-native.** Agent chat with tree tools, an MCP server mode for Claude
  Desktop and Cursor, an MCP host for external servers, and ACP agents.
- **Private by design.** No accounts, no cloud, no telemetry. The only network
  calls are the AI providers and MCP servers you configure yourself; API keys
  stay in your OS keychain, and with Ollama or LM Studio even the AI runs
  entirely on your machine.
- **Text config.** Settings and themes are plain JSON files that hot-reload —
  editable by humans and agents alike.
- **Interoperable.** GEDCOM import and export keep you connected to other
  genealogy software, and the interface is fully localized in 17 languages.

Dóru is free and open source (MIT).
